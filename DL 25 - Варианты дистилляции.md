## 1. Категоризация методов Knowledge Distillation

### Три оси классификации

Базовые принципы дистилляции — в [[DL 24 - Knowledge Distillation]].

1. **По типу передаваемых знаний** (what):
   - Response-based (logits/outputs)
   - Feature-based (intermediate representations)
   - Attention-based (attention maps)

2. **По режиму обучения** (how):
   - Offline distillation
   - Online distillation
   - Self-distillation

3. **По типу данных** (what data):
   - Natural data (оригинальные датасеты)
   - Dataset distillation (синтетические данные)

## 2. Response-based Distillation (Hinton et al., 2015)

### Идея
Student учится имитировать **финальный выход** teacher — softmax с высокой температурой.

### Формула

$$ \mathcal{L}_{KD} = T^2 \cdot D_{KL}(\sigma(z_t/T) \parallel \sigma(z_s/T)) $$

### Плюсы

| Плюс | Описание |
|------|----------|
| **Простота** | Нужны только logits teacher |
| **Любая архитектура** | Неважно, что внутри |
| **Никаких модификаций** | Student — стандартная модель |
| **Работает сразу** | Hinton показал на MNIST |

### Минусы

| Минус | Причина |
|-------|---------|
| **Только финальный ответ** | Не видит внутренние признаки |
| **Ограниченная информация** | Не передаёт mid-level features |
| **Зависимость от T** | Нужно подбирать |
| **Capacity gap** | Если student слишком мал — плохо |

### Когда применять

- Быстрое прототипирование
- Student и teacher — похожих архитектур
- Доступны только logits teacher (без интернета)

## 3. Feature-based Distillation

### Идея
Student учится имитировать **промежуточные feature maps** teacher.

### Схема

```
Teacher:   ┌── conv1 ── conv2 ── conv3 ── conv4 ── FC ── logits ┐
           │                         │                          │
           │                         ▼                          │
           │                   Feature Map                      │
           │                         │                          │
Student:   ┌── conv1 ── conv2 ── conv3 ── conv4 ── FC ── logits ┐
           │                         │                          │
           │                         ▼                          │
           │                    Feature Map L2 / MSE            │
           └────────────────────────────────────────────────────┘
```

### Loss

$$ \mathcal{L}_{feat} = \sum_{l \in \mathcal{L}} \lambda_l \cdot \mathcal{D}\left(f_t^{(l)}(x), f_s^{(l)}(x)\right) $$

Где:
- $f_t^{(l)}$, $f_s^{(l)}$ — feature maps на слое $l$
- $\mathcal{D}$ — функция расстояния (обычно MSE)
- $\lambda_l$ — вес для каждого слоя

### Функции расстояния

| Метод | $\mathcal{D}$ | Особенность |
|-------|---------------|-------------|
| **MSE** (FitNets) | $\|f_t - f_s\|^2$ | Прямое совпадение |
| **L1** | $\|f_t - f_s\|$ | Менее чувствительна к выбросам |
| **Cosine** | $1 - \cos(f_t, f_s)$ | Инвариантна к масштабу |
| **Normalized MSE** | $\left\|\frac{f_t}{\|f_t\|} - \frac{f_s}{\|f_s\|}\right\|^2$ | Инвариантна к масштабу |

### FitNets (Romero et al., 2015)

**Ключевая идея**: student может быть **глубже (thin but deep)**, чем teacher.

**Hint learning**:
1. Обучить student имитировать teacher на промежуточном слое (hint layer)
2. Затем fine-tune с response-based KD

**Hint training loss**:
$$ \mathcal{L}_{hint} = \frac{1}{2} \| r(h_s) - h_t \|^2 $$

Где $r(\cdot)$ — дополнительный projection layer (для dimensional alignment).

### Проблемы Feature-based KD

| Проблема | Решение |
|----------|---------|
| **Разные размеры feature maps** | Projection layer (1×1 Conv) |
| **Какой слой выбрать?** | Эмпирически или validation |
| **Teacher intermediate может быть неоптимален** | Rescaling, attention |
| **Сложнее обучение** | Много гиперпараметров |

### Плюсы

- Больше информации, чем response-only
- Передача mid-level признаков
- Лучший результат для сильно сжатых моделей

## 4. Attention Transfer (Zagoruyko & Komodakis, 2017)

### Идея
Вместо точных feature maps — перенос **attention maps** (тепловых карт внимания).

### Attention Map

$$ A_l = \frac{1}{C} \sum_{c=1}^{C} |F_{l,c}|^p $$

Где:
- $F_{l,c}$ — c-й канал feature map на слое $l$
- $p$ — степень (1 или 2)
- $A_l$ — attention (усреднение/сумма по каналам)

### Variants of Attention

| Тип | Формула | Комментарий |
|-----|---------|-------------|
| **Sum** | $\sum_{c=1}^{C} |F_{c}|^2$ | Активация |

---

**Варианты:**

$$ A = \sum_{c=1}^{C} |F_c|^2 $$
$$ A = \max_{c=1}^{C} |F_c| $$
$$ A = \frac{1}{C} \sum_{c=1}^{C} |F_c| $$

### Loss

$$ \mathcal{L}_{AT} = \sum_{j \in \mathcal{J}} \left\| \frac{A_t^{(j)}}{\|A_t^{(j)}\|_2} - \frac{A_s^{(j)}}{\|A_s^{(j)}\|_2} \right\|_2 $$

Где $\mathcal{J}$ — набор пар слоёв teacher и student.

### Плюсы vs Feature-based

| Аспект | Feature-based | Attention Transfer |
|--------|--------------|-------------------|
| **Что передаём** | Все каналы | Карта активации (1×H×W) |
| **Канальная специфика** | ✅ | ❌ (потеряна) |
| **Пространственная структура** | ✅ | ✅ |
| **Параметры проекции** | ✅ (proj layer) | ❌ Не нужны |
| **Компактность** | Низкая | ✅ Высокая |
| **Результат** | Лучше при близких архитектурах | Лучше при разных |

## 5. Offline Distillation

### Процесс

```
Шаг 1: Обучить Teacher (большая модель, полные данные)
Шаг 2: Teacher → predictions на train set → save logits
Шаг 3: Обучить Student (hard labels + teacher logits)
```

### Особенности

| Характеристика | Значение |
|----------------|----------|
| **Teacher frozen** | ✅ Да (не обновляется) |
| **Данные** | Не нужно teacher на инференсе |
| **Скорость** | Один forward teacher на все данные |
| **Хранение** | logits на диске (пр. CIFAR-10 → 5MB) |
| **Качество** | Хорошее (teacher — лучшая модель) |

### Pipeline

```python
# Шаг 1: Обучить teacher
teacher.fit(train_data)

# Шаг 2: Сохранить logits
teacher_logits = teacher.predict(train_data)
save(teacher_logits)

# Шаг 3: Обучить student
for x, y, t_logits in dataloader:
    s_logits = student(x)
    loss = alpha * CE(s_logits, y) + (1-alpha) * KL(t_logits/T, s_logits/T)
```

### Преимущества

- Teacher обучается один раз
- logits можно сохранить и переиспользовать
- Student не требует teacher во время обучения

## 6. Online Distillation

### Процесс
Teacher и student обучаются **одновременно**. Teacher тоже обновляется.

### Особенности

| Характеристика | Offline | Online |
|----------------|---------|--------|
| **Teacher frozen** | ✅ | ❌ (обновляется) |
| **Скорость** | Быстрее | Медленнее (оба обучаются) |
| **Teacher качество** | Изначально лучше | Растёт вместе со student |
| **Когда нужен** | Большой teacher есть | Teacher нет; пара обучается вместе |
| **Архитектура** | Фиксирована | Teacher может меняться |

### Mutual Learning (Zhang et al., 2018)

Несколько моделей (peer) обучаются и обмениваются знаниями:

$$ \mathcal{L}_i = \mathcal{L}_{CE}(y, p_i) + \frac{1}{N-1} \sum_{j \neq i} D_{KL}(p_j \parallel p_i) $$

- Все модели равны (нет teacher/student)
- Каждая — и student, и teacher для других
- Эффект ансамбля без инференса ансамбля

### Deep Mutual Learning (DML)

```
Model A ── KL ── Model B
   │              │
   │ CE           │ CE
   ▼              ▼
  (y)            (y)
```

- Две сети одинаковой архитектуры
- Обе обучаются на GT + друг от друга
- В результате обе лучше, чем каждая по отдельности

### Co-distillation / Collaborative Learning

```
                 ┌────── Teacher ──────┐
                 │                      │
                 ▼                      ▼
┌─────────┐  ┌─────────┐  ┌─────────┐
│ Student1│  │ Student2│  │ Student3│
│ data1   │  │ data2   │  │ data3   │
└─────────┘  └─────────┘  └─────────┘
```

- Federated learning с дистилляцией
- Данные распределены, модели обмениваются soft predictions
- Без передачи данных (privacy)

## 7. Self-distillation

### Идея
Одна и та же модель — себе teacher. **Модель учится у себя**.

### Методы

#### A. Подготовка на более ранних эпохах

```
Teacher = модель эпохи 50
Student = модель эпохи 50 (обновлённая копия)
```

- Учимся у "более умной" версии себя
- Беглый (будущая эпоха) учит себя прошлого

#### B. Be Your Own Teacher (BYOT, Zhang et al., 2019)

```
ResNet: головы на разных глубинах
                  ┌────── Head 1 (early exit)
                  │
Backbone ─────────┼────── Head 2 (mid)
                  │
                  └────── Head 3 (deep = teacher)
```

- **Deep head** — teacher (точнее)
- **Early/mid heads** — students
- Teacher учит students (feature-based или response-based)

#### C. Born-Again Networks (Furlanello et al., 2018)

```
1. Обучить модель A → сохранить
2. Создать модель B (та же архитектура)
3. Обучить B: KD(A) + GT
4. B → лучше A!
5. Повторить: C = KD(B) + GT
```

**Парадокс**: модель той же архитектуры обучается лучше исходной!

**Почему**: teacher прошёл трудный путь оптимизации, student может "срезать углы", используя soft labels.

### Self-distillation results (CIFAR-100, WRN-28-10)

| Метод | Accuracy |
|-------|----------|
| Без KD | 80.4% |
| Self-distillation (BYOT) | 81.7% |
| Born-Again (2 gen) | 81.9% |
| Teacher (внешний) KD | 82.5% |

## 8. Dataset Distillation

### Идея
Создать **синтетический датасет небольшого размера**, который позволит обучить модель так же хорошо, как и большой датасет.

### Формально

$$ \mathcal{D}_{synth} = \arg\min_{\mathcal{D}} \mathcal{L}(\theta(\mathcal{D}), \mathcal{D}_{real}) $$

Где $\theta(\mathcal{D})$ — веса, обученные на синтетическом датасете.

### Методы

#### A. Matching Training Trajectories (Cazenavette et al., 2022)

1. Обучить teacher на реальных данных, сохранить траекторию параметров $\theta_t^*$
2. Синтезировать изображения: начать с шума, оптимизировать через gradient matching
3. **Matching loss**: student, обученный на синтезированных данных, должен следовать той же траектории

#### B. Distribution Matching

- Синтетические img должны иметь такое же распределение признаков, как реальные
- Maximum Mean Discrepancy (MMD) между real и synthetic

#### C. Gradient Matching

$$ \mathcal{L} = \left\| \nabla_{\theta} \mathcal{L}(\mathcal{D}_{synth}) - \nabla_{\theta} \mathcal{L}(\mathcal{D}_{real}) \right\|^2 $$

### Результаты

| Датасет | Размер реального | Размер синтетического | Accuracy (real) | Accuracy (synthetic) |
|---------|-----------------|----------------------|-----------------|---------------------|
| MNIST | 60K | 10/class | 99.6% | 98.8% |
| CIFAR-10 | 50K | 1/class | 96.1% | 84.1% |
| CIFAR-10 | 50K | 10/class | 96.1% | 91.5% |
| CIFAR-100 | 50K | 1/class | 80.2% | 57.9% |

### Зачем нужна Dataset Distillation

1. **Уменьшение размера данных**: 60K → 100 изображений
2. **Privacy**: синтетические данные не содержат лиц/личных данных
3. **Efficient learning**: быстрее традиционного обучения
4. **Continual learning**: не нужно хранить все старые данные
5. **Neural Architecture Search**: быстрая оценка архитектур

## 10. Практические рекомендации

### Какой метод выбрать?

| Условие | Рекомендация |
|---------|--------------|
| **Есть большой pretrained teacher** | Offline + Response-based (просто и эффективно) |
| **Student очень мал** | Добавить Feature-based / Attention Transfer |
| **Нет teacher** | Online (Mutual Learning) или Self-distillation |
| **Мало данных** | Dataset distillation + KD |
| **Privacy-critical** | Dataset distillation (синтезировать данные) |
| **Требуется SOTA** | Offline + Feature + Response (лучшее сразу) |

### Комбинация методов

Наилучший результат — **совместное использование**:

$$ \mathcal{L} = \underbrace{\mathcal{L}_{CE}(y, p_s)}_{\text{GT}} + \lambda_1 \underbrace{\mathcal{L}_{KD}(z_t, z_s)}_{\text{Response}} + \lambda_2 \underbrace{\sum_l \|f_t^{(l)} - f_s^{(l)}\|^2}_{\text{Feature}} + \lambda_3 \underbrace{\sum_l \|A_t^{(l)} - A_s^{(l)}\|^2}_{\text{Attention}} $$

---

## Ключевые выводы к экзамену

1. **Response-based**: классическая KD Hinton. Softmax с T > 1 → KL-divergence. Просто, эффективно
2. **Feature-based**: имитация промежуточных слоёв. FitNets. Нужен projection layer для alignment
3. **Attention Transfer**: имитация attention maps (не всех каналов). Не нужно выравнивание размерности
4. **Offline**: teacher frozen, logits сохранены. Стандартная практика
5. **Online**: teacher и student обучаются вместе. Mutual Learning, Collaborative Learning
6. **Self-distillation**: модель учится у себя. Born-Again Networks, BYOT. Неожиданно улучшает!
7. **Dataset distillation**: синтетические данные, имитирующие реальные. Gradient/MMD matching
8. **Выбор**: при наличии большого teacher → offline + response. При отсутствии → mutual learning
