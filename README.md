# Deep Learning Exam Prep 🧠

Конспекты для подготовки к устному экзамену по Deep Learning.

**62 вопроса** — от основ до мультимодальных моделей. Все заметки связаны между собой для удобной навигации.

## Формат
- Русский язык, формулы LaTeX, сравнительные таблицы
- Каждая заметка покрывает все подпункты вопроса
- `DL - Index.md` — корневой индекс со ссылками на все вопросы

## Как пользоваться
1. Открой `DL - Index.md`
2. Выбери вопрос
3. В конце каждой заметки — ссылки на смежные темы
