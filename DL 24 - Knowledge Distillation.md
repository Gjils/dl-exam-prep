# 24. Knowledge Distillation

## Teacher-student, soft labels, temperature, KL-divergence, зачем нужна

---

## 1. Что такое Knowledge Distillation (KD)?

### Определение
**Knowledge Distillation** — метод компрессии модели, при котором **большая/сложная модель (teacher)** передаёт знания **маленькой/простой модели (student)**.

Teacher: крупная, точная, дорогая модель
Student: компактная, быстрая, дешёвая модель

### Аналогия
Профессор (teacher) объясняет студенту (student) не просто ответы, но и **ньюансы рассуждений**.

### Мотивация

Дистилляция знаний тесно связана с [[DL 15 - Transfer Learning|transfer learning]] (перенос знаний между моделями) и является методом [[DL 43 - Ускорение и сжатие LLM|сжатия моделей]].

| Проблема | Решение через KD |
|----------|------------------|
| Большая модель дорогая для инференса | Student — маленькая модель |
| Нет данных для обучения маленькой модели | Teacher "размечает" данные |
| Однослойная сеть плохо учится | Soft labels от teacher — сигнал |
| Прунинг/квантизация теряют точность | KD восстанавливает качество |
| Ensemble — дорого на инференсе | KD — один student вместо ансамбля |

## 2. Архитектура Teacher-Student

### Концептуально

```
                   ┌─────────────┐
                   │   Teacher   │ (большая, pretrained)
                   │             │
Input ────────────▶│ logits z_t  │────▶ soft labels
                   └─────────────┘
                              │
                              ▼
┌─────────────┐          ┌──────────┐
│   Student   │          │  Distill │
│             │          │   Loss   │
│ logits z_s  │─────────▶│          │
└─────────────┘          └──────────┘
         │                     │
         ▼                     │
    Hard labels                │
    (ground truth)             │
         │                     │
         ▼                     ▼
    ┌────────────────────────────┐
    │     Combined Loss          │
    │  α·L_hard + β·L_soft       │
    └────────────────────────────┘
```

### Компоненты

| Компонент | Что делает |
|-----------|-----------|
| **Teacher** | Предобученная большая модель (заморожена) |
| **Student** | Маленькая модель, которую обучаем |
| **Hard labels** | Ground truth (обычный CE loss) |
| **Soft labels** | Teacher's output probabilities |
| **Distill loss** | KL-divergence между teacher и student logits |

---

## 3. Soft Labels (мягкие метки)

### Что это?

Вместо one-hot меток [0, 0, 1, 0, 0] — **распределение вероятностей**:

```
Hard label:     [0, 0, 1, 0, 0]
Soft label:     [0.02, 0.05, 0.85, 0.03, 0.05]
```

### Почему soft labels полезны?

**Dark knowledge (тёмные знания)**:

Для изображения "кота":
- Класс 3 (кот): 0.85
- Класс 4 (собака): 0.08 — близкое?
- Класс 1 (машина): 0.02 — непохоже
- Класс 0 (стол): 0.03

Soft label кодирует **семантическую близость**: "кот похож на собаку, но не на машину".

### Сравнение hard vs soft

| Аспект | Hard labels | Soft labels |
|--------|-------------|-------------|
| **Информация** | Только класс | + структура классов |
| **Градиент** | Нулевой для wrong classes | Ненулевой для всех |
| **Обобщение** | Меньше | ✅ Больше |
| **Overfitting** | Может быть | ✅ Меньше |
| **Шум** | Нет | Робастность |

## 4. Temperature (температура)

### Формула

$$ p_i = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)} $$

Где:
- $z_i$ — logit (log-odds) для класса i
- $T$ — температура (temperature)

### Эффект T

| T | Эффект на распределение | Пример |
|---|------------------------|--------|
| **T → 0** | Жёсткое (argmax) | [0, 0, 1, 0, 0] |
| **T = 1** | Стандартный softmax | [0.02, 0.05, 0.85, 0.03, 0.05] |
| **T > 1** | **Мягкое**, размытое | [0.15, 0.18, 0.35, 0.17, 0.15] |

### Зачем повышать температуру?

1. **Более информативные soft labels**: при T=1 мелкие вероятности (0.02) дают слабый градиент
2. **При T > 1**: все классы получают существенный градиент
3. **Эмпирика**: T = 2-8 для дистилляции, T = 1 для inference student

### Пример

```
Logits:   [2.0, 1.0, 5.0, 0.5, -1.0]

T=1:
  Softmax: [0.04, 0.02, 0.90, 0.01, 0.00]
  Student учится только классу 3

T=5:
  Softmax: [0.14, 0.12, 0.35, 0.11, 0.06]
  Student учится: "класс 3 главный, 1 и 2 тоже"
```

## 5. KL-Divergence

### Определение

$$ D_{KL}(P \parallel Q) = \sum_i P(i) \log\frac{P(i)}{Q(i)} $$

Где:
- $P$ — teacher distribution (целевое распределение)
- $Q$ — student distribution (приближение)

### Свойства

- $D_{KL} \geq 0$ (неотрицательна)
- $D_{KL} = 0$ ⇔ $P = Q$
- Несимметрична: $D_{KL}(P \parallel Q) \neq D_{KL}(Q \parallel P)$

### Distill Loss через KL

$$ \mathcal{L}_{KD} = T^2 \cdot D_{KL}(p_t \parallel p_s) $$

$$ \mathcal{L}_{KD} = T^2 \cdot \sum_i p_t(i) \log\frac{p_t(i)}{p_s(i)} $$

Где $p_t$ и $p_s$ — softmax с температурой $T$.

**Множитель $T^2$**:
- Градиент дистилляции масштабируется как $\approx 1/T^2$
- $T^2$ компенсирует этот эффект
- Позволяет использовать $\alpha$ независимо от $T$

### Связь с Cross-Entropy

$$ D_{KL}(P \parallel Q) = H(P, Q) - H(P) $$

Где:
- $H(P, Q)$ — cross-entropy
- $H(P)$ — энтропия teacher (константа)

**На практике $D_{KL}$ эквивалентна CE для фиксированного P!**

## 6. Полная loss-функция KD

### Общая формула (Hinton et al., 2015)

$$ \mathcal{L} = \alpha \underbrace{\mathcal{L}_{hard}(y, \sigma(z_s))}_{\text{Student CE с GT}} + (1 - \alpha) \underbrace{T^2 D_{KL}(\sigma(z_t/T) \parallel \sigma(z_s/T))}_{\text{Distill loss}} $$

Где:
- $y$ — ground truth
- $\sigma(\cdot)$ — softmax
- $z_t$ — teacher logits
- $z_s$ — student logits
- $T$ — temperature
- $\alpha$ — вес hard loss (типично 0.1-0.5)
- $T^2$ — нормализация градиента

### Компоненты loss

```
Hard Loss (CE):
  Учит student отвечать как GT
  - Жёсткое знание
  - Только правильный класс

Soft Loss (KL):
  Учит student имитировать teacher
  - Структура между классами
  - Все классы

Вес α:
  α = 1: только GT (без дистилляции)
  α = 0: только teacher (может переучиться на ошибки teacher)
  α = 0.1-0.5: баланс (лучший вариант)
```

## 7. Зачем нужна Knowledge Distillation?

### Основные причины

#### 1. Сжатие модели (Model Compression)

```
Teacher (ResNet-152, 60M params, 76% top-1)
    └──→ Student (ResNet-18, 11M params, 70% → 73% после KD)
```

**Выгода**: 5× меньше параметров, 2-3× быстрее, с потерей всего 3% точности (vs 6% без KD)

#### 2. Transfer Learning

```
Teacher на ImageNet → Student на маленьком датасете
```

- Student получает "знания" от teacher + данные
- Эффективно для малых датасетов

#### 3. Ensembles → Single Model

```
Teacher = Ensemble из 5 моделей (5× inference cost)
Student = 1 модель (1× cost, ~ensemble quality)
```

- Объединение знаний ансамбля в одну модель

#### 4. Прунинг и квантизация

```
Pre-trained model → Prune/Quantize → KD восстанавливает качество
```

#### 5. Предотвращение Catastrophic Forgetting

При fine-tuning: KD хранит знания старого датасета через teacher.

#### 6. Self-distillation

```
Та же архитектура → обучение себя через себя → улучшение
```

(см. вопрос 25)

## 8. Практические аспекты

### Гиперпараметры

| Параметр | Типичное | Комментарий |
|----------|----------|-------------|
| **T** | 2-8 | Выше → мягче метки |
| **α** | 0.1-0.5 | Вес hard loss |
| **T² в KL** | T² | Баланс градиента |
| **Optimizer** | Adam | Стандартный |
| **LR** | 1e-4 — 1e-3 | Обычный |

### Правила выбора параметров

1. **T**: малый датасет → выше T (больше dark knowledge)
2. **α**: точный teacher → α = 0.1-0.3; шумный → α = 0.5-0.7
3. **T²**: всегда включать для стабильности
4. **Warmup**: начинать с hard loss, постепенно вводить distill

### Когда KD НЕ работает

| Ситуация | Причина |
|----------|---------|
| Teacher плохой (< student) | Student нечему учиться |
| Capacity gap большой | Слишком мелкий student |
| Teacher не converged | Шумные soft labels |
| Teacher и student — разные задачи | Domain shift |

## 9. Пример: KD на CIFAR-100

```
Teacher: ResNet-34 (21M params, 79.4% top-1)
Student: ResNet-18 (11M params, 77.8% → 79.1% после KD)
```

| Настройки | T | α | Student accuracy |
|-----------|---|---|------------------|
| Без KD | — | — | 77.8% |
| KD | 4 | 0.5 | **79.1%** |
| KD | 8 | 0.3 | 78.8% |
| KD | 2 | 0.7 | 78.5% |

## Ключевые выводы к экзамену

1. **Knowledge Distillation**: teacher (большой) → student (маленький). Перенос знаний через soft labels
2. **Soft labels**: распределение вероятностей (не one-hot). Передают "dark knowledge" — структуру между классами
3. **Temperature**: $p_i = \frac{\exp(z_i/T)}{\sum\exp(z_j/T)}$. T > 1 → мягкое распределение, больше информации
4. **KL-divergence**: $D_{KL}(P \parallel Q) = \sum P\log\frac{P}{Q}$. Distill loss = $T^2 \cdot D_{KL}(teacher \parallel student)$
5. **Полный loss**: $\mathcal{L} = \alpha \cdot \mathcal{L}_{hard} + (1-\alpha) \cdot T^2 \cdot D_{KL}$
6. **Зачем**: сжатие моделей, ускорение, улучшение после прунинга/квантизации, замена ensemble
7. **Ключ к успеху**: правильный T (2-8) и α (0.1-0.5)
