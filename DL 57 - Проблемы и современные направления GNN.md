Базовые принципы GNN см. [[DL 56 - GNN]]. Связь с механизмом внимания: [[DL 33 - Архитектура Transformer]].

## 1. Oversmoothing (Чрезмерное сглаживание)

### Проблема

При увеличении числа слоёв GNN представления всех вершин сходятся к одному значению (становятся неразличимы).

**Причина:** message passing — это low-pass фильтрация (сглаживание). Каждый слой усредняет признаки с соседями. При $K \to \infty$, $h_v^{(K)} \to u$, где $u$ — вектор, соответствующий собственному вектору оператора Лапласа с нулевым собственным значением.

**Математически:** 

Для GCN: $H^{(k)} = \tilde{A} H^{(k-1)} W^{(k)}$

После $k$ шагов: $H^{(k)} \approx (\tilde{A})^k H^{(0)} W^*$

Асимптотически $(\tilde{A})^k \to \Pi$, где $\Pi$ — матрица, у которой все строки одинаковы.

### Решения

| Метод | Идея |
|---|---|
| **DropEdge** | Случайное удаление рёбер во время обучения |
| **PairNorm** | Нормализация для сохранения дистанций |
| **JK-Net (Jumping Knowledge)** | Соединение всех слоёв (skip connections) |
| **DAGNN (Deep Adaptive GNN)** | Адаптивный контроль сглаживания |
| **GCNII** | Residual + identity mapping |
| **Skip connections** | $h_v^{(k)} = \text{GNN}(h_v^{(k-1)}) + h_v^{(k-1)}$ |

### JK-Net (Jumping Knowledge Networks)

**Идея:** каждый слой GNN сохраняет свой вывод. В конце все слои агрегируются:

$$h_v^{(final)} = \text{AGG}\left( [h_v^{(1)}, h_v^{(2)}, \dots, h_v^{(K)}] \right)$$

**Агрегаторы:** concat + MLP, max-pooling, LSTM.

Позволяет модели гибко выбирать receptive field для каждой вершины.

### Сколько слоёв нужно?

- **Node classification:** 2-3 слоя достаточно (local + second-order neighbours)
- **Link prediction:** 1-2 слоя
- **Graph classification:** 3-5 слоёв (нужна глобальная информация)

## 2. Oversquashing (Чрезмерное сжатие)

### Проблема

Информация от дальних вершин ($>K$-hop) должна пройти через узкие места (bottleneck vertices), теряя информацию.

**Причина:** граф имеет малую пропускную способность. Если вершина $A$ должна общаться с вершиной $B$ через единственный путь из $K$ шагов, то на каждом шаге информация $A$ попадает в ограниченный вектор вершины на пути (конкурирует с информацией других вершин).

**Математически:** для вершины $v$ с степенью $d_v$, размер сообщения $O(d_v^{-K})$ теряется при $K$ итерациях через вершину с малой степенью.

**Симптомы:** модель не может использовать дальние зависимости даже с большим числом слоёв.

### Решения

| Метод | Идея |
|---|---|
| **Virtual nodes** | Добавление вершины, соединённой со всеми — shortcut |
| **Expanders** | Построение экспандерных графов (добавление случайных рёбер) |
| **Graph rewiring** | Перестроение графа для лучшей связности |
| **Leskovec rewiring** | Улучшение пропускной способности через разрежение + добавление |

**Рекомендация:** для задач, требующих глобальной информации, используйте virtual nodes или transformer-like архитектуры.

## 3. Heterophily (Гетерофилия)

### Проблема

Большинство GNN основаны на **гомофилии** — соседи похожи друг на друга. На гетерофильных графах (соседи разных классов) стандартные GNN работают хуже MLP.

**Гомофилия:** $P(y_u = c | u \in \mathcal{N}(v), y_v = c)$ высокая
**Гетерофилия:** соседи часто принадлежат разным классам

**Коэффициент гомофилии:**
$$h = \frac{1}{n} \sum_{v \in V} \frac{|\{u \in \mathcal{N}(v) : y_u = y_v\}|}{|\mathcal{N}(v)|}$$

| Граф | $h$ | Тип |
|---|---|---|
| Cora (цитирование) | 0.81 | Гомофильный |
| Pubmed | 0.80 | Гомофильный |
| Chameleon (веб-граф) | 0.23 | Гетерофильный |
| Squirrel (веб-граф) | 0.22 | Гетерофильный |

### Почему GNN не работают на гетерофильных графах?

Осреднение с соседями другого класса размывает границы между классами.

### Решения

| Архитектура | Идея |
|---|---|
| **H2GCN** | Разделение агрегации своей группы и соседей |
| **GPR-GNN** | Generalized PageRank — гибкий weights propagation |
| **GNN with ego- and neighbor- embeddings** | Разделение $h_v$ и $\text{AGG}(h_u)$ |
| **MLP + GNN combo** | Сочетание собственной информации и соседей |

**H2GCN конкретно:**
1. Разделение агрегации: отдельно $h_v$, отдельно соседи
2. Конкатенация: $[h_v^{(k)}, \sum_{u \in \mathcal{N}(v)} h_u^{(k)}]$
3. Многоуровневая агрегация

## 4. Масштабирование (Scaling)

### Проблема

Полный full-batch gradient descent на графе с миллиардами вершин невозможен.

### Решения

| Метод | Идея | Сложность |
|---|---|---|
| **GraphSAGE (neighbor sampling)** | Сэмплирование $S$ соседей на слой | $O(K S^K)$ |
| **Cluster-GCN** | Разбиение графа на кластеры | $O(K \|E\|)$ |
| **GraphSAINT** | Сэмплирование подграфа | $O(K \|E_{sample}\|)$ |
| **ShadowGNN** | DeepWalk-like сэмплирование | $O(K \|V\|)$ |
| **SIGN** | Предвычисление всех порядков propagation | $O(K \|E\|)$ (однократно) |

### Cluster-GCN

1. Разбиение графа на кластеры (Metis)
2. В каждом мини-батче один или несколько кластеров
3. Все рёбра внутри кластера используются (нет сэмплирования)
4. Проблема: теряются межкластерные рёбра → решается смешиванием кластеров

### Mini-batch training:

| Метод | Использует все рёбра | Индуктивный | Память |
|---|---|---|---|
| Full-batch | ✓ | Да | ✗ Много |
| Neighbor sampling | ✗ | ✓ | Средне |
| Cluster-GCN | ✓ | Нет | Мало |
| GraphSAINT | ✓ | ✓ | Мало |

## 5. Graph Foundation Models (GFM)

### Идея

Как LLM для текста — предобученная модель для любых графовых задач.

### Архитектуры:

| Название | Описание |
|---|---|
| **GraphGPT / OFA** | Единая архитектура для node/edge/graph задач |
| **GraphMAE** | Masked graph autoencoding (как BERT для графов) |
| **GNN + LLM** | Комбинация GNN и языковых моделей |
| **Task-specific adapters** | LoRA/адаптеры для разных задач |

### Проблемы GFM:

- **Разные графы** имеют разную структуру — сложно найти универсальное представление
- **Feature engineering**: разные задачи имеют разные признаки
- **Transfer learning**: перенос на новые графы низкого качества (пока)

## 6. Современные тенденции

| Направление | Описание |
|---|---|
| **Graph Transformers** | Замена message passing на self-attention (Graphormer, GPS) |
| **Equivariant GNNs** | Учёт симметрий (ротация, трансляция) для 3D-графов (молекулы) |
| **Temporal GNNs** | Учёт временной динамики графов |
| **Heterogeneous GNNs** | Разные типы вершин и рёбер (HGT, RGCN) |
| **Geometric DL** | GNN+ диффузионные операторы (GNN on manifolds) |
| **Large-scale GNNs** | Facebook, Pinterest-pinnable — масштабирование до миллиардов |
| **Explainable GNN** | Объяснение предсказаний (GNNExplainer, SubgraphX) |

### Graph Transformer

**GPS (General, Powerful, Scalable)** — комбинация:
- Message passing (локальная информация)
- Self-attention (глобальная информация)
- Positional encoding (Laplacian PE, Random Walk PE)

$$\text{GPS Layer}(X) = \text{MPNN}(X) + \text{Attention}(X + PE)$$
