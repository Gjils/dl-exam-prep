# 60. Мультимодальные задачи и CLIP

## 1. Мультимодальные задачи

**Мультимодальное обучение** — работа с данными разных модальностей (текст, изображение, аудио, видео). Основные задачи:

| Задача | Вход | Выход | Пример |
|---|---|---|---|
| **Image-Text Retrieval** | изображение / текст | релевантный текст / изображение | Поиск по картинке |
| **Zero-shot Classification** | изображение + список классов | класс | Классификация без обучения |
| **Visual Question Answering** | изображение + вопрос | ответ | "Что на картинке?" |
| **Image Captioning** | изображение | описание | "Кошка на диване" |
| **Text-to-Image** | текст | изображение | Stable Diffusion |
| **Visual Grounding** | текст + изображение | bounding box | "Найди кошку" |

## 2. CLIP (Contrastive Language-Image Pre-training)

**CLIP** (Radford et al., 2021, OpenAI) — модель для обучения совместных представлений изображений и текста.

### Основная идея

CLIP учится сопоставлять изображения и текст в общем латентном пространстве через **контрастивное обучение** на 400M парах (изображение, текст) из интернета.

### Архитектура CLIP:

```
Image → Image Encoder (ViT/ResNet) → I_i ∈ R^d
Text  → Text Encoder (Transformer)   → T_j ∈ R^d
```

**Image Encoder:** [[DL 51 - Vision Transformer|ViT]] (Vision Transformer) или [[DL 14 - ResNet|ResNet]]
**Text Encoder:** [[DL 33 - Архитектура Transformer|Transformer]] (обычно 63M параметров, 12 слоёв, 512 hidden)

### Image-Text Contrastive Learning

**Парадигма:** batch из $N$ пар (изображение, текст). CLIP учится предсказывать, какие $N^2$ пар (изображение, текст) являются правильными.

Формируются две матрицы:

$$I_c = \text{L2Norm}(I_i) \in \mathbb{R}^d \quad \text{(нормализованные эмбеддинги изображений)}$$
$$T_c = \text{L2Norm}(T_j) \in \mathbb{R}^d \quad \text{(нормализованные эмбеддинги текстов)}$$

Матрица сходства:

$$S = I_c T_c^\top \in \mathbb{R}^{N \times N}$$

$S_{ij}$ — косинусное сходство между i-м изображением и j-м текстом.

## 3. InfoNCE Loss (Contrastive Loss)

CLIP использует **InfoNCE** (Info Noise Contrastive Estimation):

$$L_I = -\frac{1}{N} \sum_{i=1}^N \log \frac{\exp(S_{ii} / \tau)}{\sum_{j=1}^N \exp(S_{ij} / \tau)}$$

$$L_T = -\frac{1}{N} \sum_{j=1}^N \log \frac{\exp(S_{jj} / \tau)}{\sum_{i=1}^N \exp(S_{ij} / \tau)}$$

$$L_{CLIP} = L_I + L_T$$

где:
- $\tau$ — обучаемая **температура** (скаляр, инициализируется $\approx 0.07$)
- $S_{ii}$ — сходство правильной пары (диагональ)
- $L_I$ — loss по изображениям (правильный текст среди N отрицательных)
- $L_T$ — loss по текстам (правильное изображение среди N отрицательных)

### Почему InfoNCE?

- Увеличивает сходство правильных пар (pull positive)
- Уменьшает сходство неправильных пар (push negatives)
- Размер батча $N$ играет роль: больше $N$ → больше негативных примеров → лучше обучение
- CLIP использует батч 32768

### Разбор cross-entropy для CLIP:

Для каждого изображения $I_i$:
- Положительная пара: $(I_i, T_i)$
- Отрицательные: $(I_i, T_j), j \neq i$
- Softmax над сходствами, CE с меткой "i" (правильный индекс)

### Температура $\tau$:

Маленькая $\tau$ → острый softmax → модель "увереннее" в правильной паре.
CLIP обучает $\tau$ как параметр (с ограничением $\tau > 0.01$ чтобы избежать взрыва градиентов).

## 4. Zero-shot Classification

CLIP позволяет классифицировать изображения **без обучения** на конкретном датасете.

### Алгоритм:

1. Создаём текстовый промпт для каждого класса:
   - "a photo of a {class}"
   - "a picture of a {class}"
   - Возможно ensemble промптов (80 вариантов в оригинале)
2. Кодируем все тексты классов через Text Encoder
3. Кодируем изображение через Image Encoder
4. Выбираем класс с максимальным косинусным сходством:

$$y = \arg\max_c \frac{I_i \cdot T_c}{\|I_i\| \|T_c\|}$$

### Prompt Engineering in CLIP:

| Промпт | Accuracy (ImageNet) |
|---|---|
| "a photo of a {class}" | 68.3% |
| Ensemble of 80 prompts | 76.2% |

**Ensemble промптов:** усреднение эмбеддингов нескольких шаблонов для каждого класса.

### Результаты zero-shot CLIP (оригинальная статья):

| Датасет | ResNet-50 (supervised) | CLIP (zero-shot) |
|---|---|---|
| ImageNet | 76.2% | 76.2% |
| CIFAR-10 | 97.0% | 95.6% |
| CIFAR-100 | 88.5% | 79.9% |
| Oxford Pets | 94.1% | 91.3% |
| Caltech-101 | 94.8% | 91.4% |
| Food-101 | 89.2% | 86.7% |

**Важно:** CLIP достигает точности ResNet-50 на ImageNet без обучения! Это демонстрирует силу контрастивного предобучения.

### Ограничения zero-shot CLIP:

| Ограничение | Пример |
|---|---|
| **Специфичные классы** | Плохо на узких доменах (медицина, спутники) |
| **Абстрактные понятия** | Hateful memes — не понимает контекст |
| **Схожие классы** | "Мопс" vs "Бульдог" — низкая точность |
| **Семантика текста** | Путает "a dog and a cat" vs "a cat and a dog" |
| **Нарушение распределения** | Необычные углы / искажения |

## 5. Сильные стороны CLIP

| Сильная сторона | Описание |
|---|---|
| **Zero-shot learning** | Классификация без обучения — работает на многих датасетах |
| **Масштабируемость** | Чем больше данных — тем лучше (scaling law) |
| **Гибкость** | Легко адаптировать к новым классам через текст |
| **Robustness** | Устойчивее к distribution shift, чем ImageNet-обученные модели |
| **Joint embedding** | Единое пространство для текста и изображений |
| **Открытые представления** | Image encoder можно использовать для downstream задач |

### Robustness к distribution shift:

CLIP меньше падает в точности при:
- Искажениях изображения
- Изменении стилей (фото → картина, скетч)
- Адверсариальных атаках (но не идеально)

## 6. Ограничения CLIP

| Ограничение | Подробно |
|---|---|
| **Слабый Text Encoder** | Не понимает сложную семантику (композиционность) |
| **Базовые промпты** | Плохо на специализированных задачах |
| **Паразитические корреляции** | Использует фон, форму и т.д. |
| **Fine-grained** | Различает, но не идеально (Omnibenchmark) |
| **Group robustness** | Может использовать нежелательные признаки |

### Примеры ошибок:

- "a photo of a cat" → находит кошек, но может ошибиться на породах
- "a photo of a food, unhealthy" → путает с контекстом
- Специальные термины ("X-ray with pneumonia") → плохо

## 7. CLIP vs Supervised

| Аспект | CLIP (zero-shot) | Supervised (ImageNet learned) |
|---|---|---|
| **Данные для обучения** | 400M пар (image, text) | 1.3M (ImageNet) |
| **Классы** | Любые текстовые | Фиксированный набор |
| **Точность** | Конкурентная | Часто выше на ID |
| **Robustness** | ✓ Выше (на OOD) | Низкая на OOD |
| **Архитектура** | ViT/ResNet + Transformer | CNN/ViT + FC head |
| **Fine-tuning** | Простой (linear probe) | Переобучение головы |

### CLIP как foundation model:

CLIP Image Encoder используется как backbone для:
- Segment Anything (SAM)
- [[DL 59 - Условная и ускоренная диффузия|DALL-E и Stable Diffusion]] (text-to-image)
- [[DL 61 - VLM и MLLM|VLM]] (Visual Question Answering, Image captioning)
- Many downstream multimodal models

Подробнее об оценке мультимодальных моделей см. [[DL 62 - Оценка и ограничения мультимодальных моделей]].

CLIP использует парадигму [[DL 34 - Pretraining в NLP|contrastive pretraining]], перенесённую из NLP в мультимодальную область.
