# DL 03 — Обучение нейронной сети

## 1. Обучение как оптимизация

Обучение нейронной сети — это задача **численной оптимизации**:

> Найти параметры $\theta = (W_1, b_1, W_2, b_2, \dots)$, минимизирующие ошибку на обучающих данных.

Минимизируем **функцию потерь** (loss function) $\mathcal{L}(\theta)$.

---

## 2. Функция потерь (Loss Function)

Функция потерь $\mathcal{L}(y, \hat{y})$ оценивает, насколько предсказание $\hat{y} = f_\theta(x)$ далеко от истинного значения $y$.

### 2.1. Для регрессии

**MSE (Mean Squared Error)**:

$$\mathcal{L} = \frac{1}{N}\sum_{i=1}^{N} (y_i - \hat{y}_i)^2$$

- Производная: $\frac{\partial \mathcal{L}}{\partial \hat{y}} = -\frac{2}{N}(y - \hat{y})$
- Чувствительна к выбросам (квадрат даёт большой вес).

**MAE (Mean Absolute Error)**:

$$\mathcal{L} = \frac{1}{N}\sum_{i=1}^{N} |y_i - \hat{y}_i|$$

- Менее чувствительна к выбросам.
- Производная не определена в 0.

**Huber Loss** (компромисс):

$$\mathcal{L}_\delta = \begin{cases} \frac12(y - \hat{y})^2 & \text{для } |y - \hat{y}| \le \delta \\ \delta|y - \hat{y}| - \frac12\delta^2 & \text{иначе} \end{cases}$$

### 2.2. Для классификации

**Cross-Entropy Loss** (совместно с Softmax):

$$\mathcal{L} = -\sum_{c=1}^{K} y_c \log \hat{y}_c$$

где $y_c = 1$ для истинного класса, иначе 0 (one-hot encoding).

Для **бинарной классификации** (Binary Cross-Entropy / BCE):

$$\mathcal{L} = -[y \log \hat{y} + (1-y)\log(1-\hat{y})]$$

**Почему Cross-Entropy, а не MSE для классификации?**

| Loss | Проблема |
|---|---|
| MSE + Softmax | Градиент затухает при сильной уверенности модели (даже если ответ неверен) |
| Cross-Entropy | Градиент пропорционален ошибке — сильнее наказывает уверенно неверные ответы |

## 3. Эмпирический риск (Empirical Risk Minimization, ERM)

Истинный риск (ожидаемая ошибка на всём распределении данных $p(x,y)$):

$$\mathcal{R}(\theta) = \mathbb{E}_{(x,y) \sim p}\big[\mathcal{L}(y, f_\theta(x))\big]$$

Мы не знаем $p(x,y)$, поэтому минимизируем **эмпирический риск** — среднюю ошибку на обучающей выборке:

$$\mathcal{R}_{\text{emp}}(\theta) = \frac{1}{N}\sum_{i=1}^{N} \mathcal{L}(y_i, f_\theta(x_i))$$

**Проблема**: ERM может привести к [[DL 08 - Диагностика обучения|переобучению]] — модель запоминает обучающие данные, но не обобщается.

---

## 4. Mini-batch Training

Невозможно загрузить весь датасет в память и посчитать градиент за один шаг (особенно если $N \sim 10^6$).

Решение: [[DL 05 - Оптимизация|стохастический градиентный спуск с mini-batches]].

### Градация:

| Метод | Размер батча | Шум градиента | Скорость шага |
|---|---|---|---|
| **Batch GD** | $N$ (весь датасет) | Нет | Медленно |
| **SGD** | 1 | Очень шумно | Быстро, но хаотично |
| **Mini-batch SGD** | 16–1024 | Умеренно | Оптимальный баланс |

### Почему mini-batch?

1. **Память**: не держим все данные в GPU RAM.
2. **Шум градиента**: стохастический шум помогает выходить из локальных минимумов (regularization effect).
3. **Эффективность**: матричные операции на батче эффективнее на GPU (SIMD парадигма).
4. **Сходимость**: на порядок быстрее batch GD.

Размер батча — гиперпараметр:
- **Small** (16–64): больше шума, лучше генерализация, медленнее на GPU (недозагрузка).
- **Large** (256–1024): стабильнее, эффективнее на GPU, но может ухудшить обобщение (меньше шума).

### Примерный пайплайн:

```python
for epoch in range(num_epochs):
    for batch_x, batch_y in dataloader:  # mini-batch
        pred = model(batch_x)
        loss = criterion(pred, batch_y)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
```

## 5. Train / Validation / Test Split

Три независимых множества для разных целей:

| Split | Назначение | Типичный размер |
|---|---|---|
| **Train** | Обучение (минимизация loss) | 60–80% |
| **Validation** | Выбор гиперпараметров, [[DL 06 - Стабилизация и регуляризация|early stopping]] | 10–20% |
| **Test** | [[DL 08 - Диагностика обучения|Финальная оценка обобщения]] | 10–20% |

### Иерархия принятия решений:

1. **Train**: модель видит эти данные — градиенты обновляют веса.
2. **Validation**: НЕ используется для градиентов. Используется для:
   - Выбора learning rate
   - Выбора архитектуры (число слоёв, нейронов)
   - Early stopping
   - Сравнения разных моделей
3. **Test**: оценивается **один раз** в конце. Если мы смотрим на test loss и меняем гиперпараметры — это leakage!

### Различные стратегии:

**Simple split**: train 70%, val 15%, test 15% (для больших датасетов).

**K-fold cross-validation**:

$$\text{Оценка} = \frac{1}{K} \sum_{k=1}^{K} \text{Score}_k$$

- Для маленьких датасетов ($N < 10^4$)
- Обучаем $K$ раз, каждый раз другая fold — val
- Дорого для глубоких сетей

**Stratified split**: сохранить пропорции классов в каждом split (важно для несбалансированных данных).

## 6. Общий алгоритм обучения

```
1. Инициализировать параметры θ
2. for epoch = 1..E:
3.   for each mini-batch (x_b, y_b) ~ D_train:
4.     y_hat = f_θ(x_b)              # forward pass
5.     loss = L(y_b, y_hat)          # вычисление потерь
6.     ∇θ = ∂loss/∂θ                 # backward pass ([[DL 04 - Backpropagation и autodiff|backprop]])
7.     θ = θ - lr · ∇θ               # шаг [[DL 05 - Оптимизация|оптимизации]]
8.   Оценить loss на validation set
9.   Если validation loss перестал улучшаться: early stopping
10. Финальная оценка на test set
```

---

## 7. Резюме

- **Функция потерь**: MSE для регрессии, Cross-Entropy для классификации.
- **Эмпирический риск**: средняя ошибка на train — то, что минимизируем.
- **Mini-batch training**: оптимальный баланс скорости, памяти и шума градиента.
- **Train/Val/Test split**: строгое разделение для честной оценки обобщения.
- **Validation** — для гиперпараметров, **Test** — финальная оценка (один раз).
