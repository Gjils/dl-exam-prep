# DL 06 — Стабилизация и регуляризация

## 1. Две проблемы глубоких сетей

| Проблема | Симптом | Причина |
|---|---|---|
| **Нестабильность обучения** | Loss = NaN, не сходится | Исчезающий/взрывной градиент, плохая инициализация |
| **Переобучение (overfitting)** | Низкий train loss, высокий test loss | Модель запоминает данные, а не обобщает |

Для каждой — свой набор техник.

---

## 2. Инициализация весов (Weight Initialization)

Плохая инициализация → дисперсия активаций растёт/падает с глубиной → исчезающий/взрывной градиент.

### Проблема наивной инициализации (нули или случайные большие числа):

**Все нули** → все нейроны получают одинаковый градиент → симметрия не нарушается → сеть не учится.

**Случайные большие** → $z = Wx$ имеет большую дисперсию → после ReLU/sigmoid насыщение → градиент = 0.

### Правильные инициализации:

| Инициализация | Формула | Для активации | Идея |
|---|---|---|---|
| **Xavier (Glorot)** | $W \sim \mathcal{U}\left(-\frac{\sqrt{6}}{\sqrt{n_{in}+n_{out}}}, \frac{\sqrt{6}}{\sqrt{n_{in}+n_{out}}}\right)$ | Tanh, Sigmoid | Сохраняет дисперсию сигнала |
| **He (Kaiming)** | $W \sim \mathcal{N}(0, \frac{2}{n_{in}})$ | ReLU, Leaky ReLU | Учитывает, что ReLU обнуляет половину |
| **Orthogonal** | $W = Q$, где $Q$ — ортогональная | RNN, ResNet | Сохраняет норму градиента |

### Почему He лучше Xavier для ReLU?

ReLU обнуляет половину нейронов → дисперсия уменьшается вдвое. He компенсирует это:

$$\text{Var}[W_{\text{He}}] = \frac{2}{n_{in}} \quad \text{vs} \quad \text{Var}[W_{\text{Xavier}}] = \frac{1}{n_{in}}$$

### Инициализация bias:
- Обычно $b = 0$
- Для ReLU можно $b = 0.01$ (чтобы избежать "умирающих" нейронов на старте)

Правильная инициализация критически важна для стабильной работы [[DL 05 - Оптимизация|оптимизаторов]].

## 3. Нормализация (Normalization)

### 3.1. Batch Normalization (BN)

Нормализует активации внутри каждого mini-batch:

$$y = \gamma \frac{x - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}} + \beta$$

где $\mu_B, \sigma_B$ — среднее и дисперсия батча, $\gamma, \beta$ — обучаемые параметры.

**На train**: нормализуем по батчу.
**На eval**: используем скользящее среднее $\mu_{\text{running}}, \sigma_{\text{running}}$.

**Эффекты:**
- Стабилизирует обучение (можно выше $\eta$)
- Уменьшает зависимость от инициализации
- Слабый регуляризатор (шум от батча)
- **Зависит от размера батча** — плохо для small batch. Альтернатива: [[DL 08 - Диагностика обучения|LayerNorm]] или GroupNorm.

### 3.2. Layer Normalization

Нормализует по **признакам** (вдоль hidden dimension):

$$y = \gamma \frac{x - \mu_L}{\sqrt{\sigma_L^2 + \epsilon}} + \beta$$

$\mu_L, \sigma_L$ считаются по одному примеру, а не по батчу.

**Когда**: Transformer (GPT, BERT), RNN, small batch.

### 3.3. Group Normalization

Промежуточный вариант: делит каналы на группы, нормализует внутри каждой.

**Когда**: когда batch размер мал (видео, медицинские изображения, object detection).

### Сравнение:

| Normalization | По чему считает | Зависит от batch? | Где используется |
|---|---|---|---|
| **BatchNorm** | Batch + Channel | **Да** | CNN (CV) |
| **LayerNorm** | Hidden dim | Нет | Transformer, RNN |
| **GroupNorm** | Группы каналов | Нет | Video, Medical, Small batch |
| **InstanceNorm** | Один пример, один канал | Нет | Style Transfer |

## 4. Dropout

Техника регуляризации: на каждом шаге **случайно обнуляем** долю $p$ нейронов.

$$h_{\text{drop}} = h \odot m, \quad m_i \sim \text{Bernoulli}(1-p)$$

**На train**: применяем Dropout (случайно отключаем нейроны).
**На eval**: отключаем Dropout, масштабируем веса на $(1-p)$ (или используем inverted dropout — масштабируем на train).

### Почему работает:
- Ансамблевый эффект (тренируем $2^N$ подсетей)
- Предотвращает коадаптацию нейронов (не могут слишком полагаться друг на друга)
- Аналог L2-регуляризации (Kingma et al., 2015)

### Monte Carlo Dropout:

На eval включаем Dropout и делаем несколько forward passes → получаем распределение предсказаний (uncertainty estimation).

## 5. Weight Decay (L2-регуляризация)

Добавляем штраф за большие веса:

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{data}} + \frac{\lambda}{2} \sum_{l} \|W^{(l)}\|_2^2$$

Влияние на градиент SGD:

$$W_{t+1} = W_t - \eta (\nabla\mathcal{L}_{\text{data}} + \lambda W_t)$$

Это **weight decay** — веса экспоненциально затухают к нулю со скоростью $\lambda$.

### Weight Decay ≠ L2 в AdamW

В Adam (и других адаптивных) L2 смешивается с адаптивной скоростью → не даёт нужного эффекта.
**AdamW** решает: применяет weight decay отдельно от градиента.

Типичное $\lambda$: $10^{-5}$ до $10^{-2}$.

## 6. Early Stopping

Следим за validation loss, останавливаемся, когда он перестаёт улучшаться:

```
Сохраняем лучшую модель (с минимальным val loss)
Если val loss не улучшается K эпох (patience) → стоп
```

**Зачем**: предотвращает переобучение, экономит время.

### Пример:

```python
best_val_loss = float('inf')
patience = 10
counter = 0

for epoch in range(epochs):
    # ... train ...
    val_loss = evaluate(model, val_loader)
    
    if val_loss < best_val_loss:
        best_val_loss = val_loss
        torch.save(model.state_dict(), 'best.pth')
        counter = 0
    else:
        counter += 1
        if counter >= patience:
            print(f"Early stopping at epoch {epoch}")
            break
```

## 7. Data Augmentation

**Генерация новых обучающих примеров** из существующих через реалистичные преобразования.

### Для изображений:

```
Оригинал → Поворот, Crop, Flip, Color jitter, Cutout, Mixup
```

### Классические методы:

| Аугментация | Суть | Применение |
|---|---|---|
| Random Horizontal Flip | Зеркальное отражение | CV (кроме текста, асимметричных объектов) |
| Random Crop | Вырезать случайный патч | Обучение устойчивости к сдвигу |
| Color Jitter | Изменение яркости, контраста, насыщенности | Устойчивость к освещению |
| Cutout / Random Erasing | Закрасить случайный квадрат | Борьба с occlusion |
| Mixup | Линейная комбинация двух изображений + меток | Сильная, простая |
| RandAugment | Автоматический подбор аугментаций | SOTA |

### Почему работает:
- Увеличивает эффективный размер датасета
- Вносит инвариантность к трансформациям
- Регуляризация через шум

## 8. Дополнительные техники стабилизации

### Gradient Clipping
Обрезаем градиент, если его норма превышает порог:

$$g \gets \frac{g}{\|g\|} \cdot \text{max\_norm}$$

### [[DL 14 - ResNet|Skip Connections (Residual)]]
$$y = F(x) + x$$

Градиент может течь напрямую через skip → **решает проблему исчезающего градиента** для очень глубоких сетей (>100 слоёв).

### Label Smoothing
Вместо one-hot меток $[1, 0, 0, \dots]$ используем:

$$y_{\text{smoothed}} = (1-\epsilon) \cdot y_{\text{one-hot}} + \epsilon \cdot \frac{1}{K}$$

Уменьшает overconfidence, улучшает калибровку.

### Stochastic Depth
Случайно пропускаем целые слои (Dropout для [[DL 14 - ResNet|ResNet]] блоков).

## 10. Резюме

- **Инициализация**: Xavier для tanh, He для ReLU.
- **Нормализация**: BatchNorm → стабильность и скорость; LayerNorm → Transformer/RNN.
- **Dropout**: случайное обнуление нейронов (регуляризация).
- **Weight Decay**: L2 штраф ([[DL 05 - Оптимизация|AdamW]] для адаптивных оптимизаторов).
- **Early Stopping**: следим за validation loss.
- **Data Augmentation**: бесплатный прирост данных.
- **Главное правило**: сначала стабилизируй обучение, потом добавляй регуляризацию.
