# 20. Object Detection

## Постановка, bounding boxes, confidence, IoU, отличия от classification и segmentation

---

## 1. Постановка задачи Object Detection

### Определение
**Object Detection** — задача определения **местоположения** и **класса** всех объектов на изображении.

### Формальная постановка
Для входного изображения $\mathcal{I} \in \mathbb{R}^{H \times W \times 3}$ найти:

$$ \mathcal{D} = \{ (b_i, c_i, s_i) \mid i = 1, \ldots, N \} $$

Где:
- $b_i = (x_1, y_1, x_2, y_2)$ — bounding box (координаты углов)
- $c_i \in \{1, \ldots, K\}$ — класс объекта
- $s_i \in [0, 1]$ — confidence score (уверенность модели)
- $N$ — количество объектов (переменное, неизвестное заранее)

### Пример вывода модели
```json
[
  {"bbox": [120, 50, 300, 400], "class": "dog", "conf": 0.95},
  {"bbox": [450, 200, 580, 450], "class": "cat", "conf": 0.87},
  {"bbox": [10, 10, 100, 100],  "class": "ball", "conf": 0.32}
]
```

## 2. Bounding Box (BBox)

### Определение
Прямоугольник, описывающий объект. Задаётся разными способами.

### Форматы

| Формат | Компоненты | Пример |
|--------|-----------|--------|
| **XYXY** | $(x_1, y_1, x_2, y_2)$ | Левый-верхний, правый-нижний угол |
| **XYWH** | $(x, y, w, h)$ | Центр (x,y), ширина, высота |
| **CXCYWH** | $(c_x, c_y, w, h)$ | Центр-координаты |

### Преобразования

$$ x_1 = c_x - \frac{w}{2}, \quad y_1 = c_y - \frac{h}{2} $$
$$ x_2 = c_x + \frac{w}{2}, \quad y_2 = c_y + \frac{h}{2} $$

### BBox в глубоком обучении

Детектор обычно предсказывает **смещения** относительно anchor или сетки:

**YOLO-style**: 
$$ t_x = \sigma(p_x) + g_x, \quad t_y = \sigma(p_y) + g_y $$
$$ t_w = p_w \cdot e^{d_w}, \quad t_h = p_h \cdot e^{d_h} $$

Где $(g_x, g_y)$ — координаты ячейки сетки, $(p_w, p_h)$ — anchor размеры.

## 3. Confidence Score

### Определение
Число от 0 до 1, показывающее **уверенность модели** в предсказании.

### Компоненты confidence в детекторах

**Two-stage (Faster R-CNN)**:
$$ \text{score} = P(\text{object}|\text{RoI}) \cdot P(\text{class}|\text{object}) $$

**One-stage (YOLO)**:
$$ \text{confidence} = P(\text{object}) \cdot \text{IoU}(pred, truth) $$

### Что означает confidence

| Score | Интерпретация |
|-------|---------------|
| 0.95 | Почти наверняка объект, точный box |
| 0.70 | Скорее всего объект |
| 0.30 | Может быть объект, может нет |
| < 0.10 | Скорее всего фон |

**Порог confidence**: типично 0.4 — 0.7 (зависит от задачи и цены FP/FN)

## 4. IoU (Intersection over Union)

### Определение

$$ \text{IoU} = \frac{\text{Area of Overlap}}{\text{Area of Union}} $$

### Геометрически

```
┌─────────┐
│  A      │
│    ┌────┼────┐
│    │Over│    │
└────┼────┘    │
     │    B    │
     └─────────┘
```

$$ \text{IoU} = \frac{|A \cap B|}{|A \cup B|} = \frac{|A \cap B|}{|A| + |B| - |A \cap B|} $$

### Алгоритм вычисления

```python
def iou(box1, box2):
    x1 = max(box1[0], box2[0])
    y1 = max(box1[1], box2[1])
    x2 = min(box1[2], box2[2])
    y2 = min(box1[3], box2[3])

    inter = max(0, x2 - x1) * max(0, y2 - y1)
    area1 = (box1[2] - box1[0]) * (box1[3] - box1[1])
    area2 = (box2[2] - box2[0]) * (box2[3] - box2[1])
    union = area1 + area2 - inter

    return inter / union if union > 0 else 0
```

### Что означает IoU

| IoU | Интерпретация |
|-----|---------------|
| 1.0 | Идеальное совпадение |
| 0.7 — 0.9 | Хорошее совпадение |
| 0.5 — 0.7 | Приемлемое для детекции |
| 0.3 — 0.5 | Плохое (объект найден, но плохо) |
| 0.0 — 0.3 | Несовпадение |

### Использование IoU в детекции

| Назначение | Описание |
|------------|----------|
| **Матчинг GT и prediction** | IoU > 0.5 → TP |
| **NMS** | Удаление дублирующихся box через IoU |
| **Метрика** | AP@0.5, AP@0.75, AP@[0.5:0.95] |
| **Anchor assignment** | IoU с GT → positive/negative anchor |
| **Loss** | IoU loss, GIoU loss, DIoU loss, CIoU loss |

### Варианты IoU Loss

| Loss | Формула | Особенность |
|------|---------|-------------|
| **IoU** | $1 - \text{IoU}$ | Нет градиента при непересечении |
| **GIoU** | $1 - \text{IoU} + \frac{|C \setminus (A \cup B)|}{|C|}$ | Работает при разъединении |
| **DIoU** | $1 - \text{IoU} + \frac{\rho^2(b, b^{gt})}{c^2}$ | Учитывает расстояние центров |
| **CIoU** | DIoU + $\alpha v$ | + aspect ratio |

## 5. Отличия от Classification и Segmentation

### Три задачи CV

```
                    ┌──────────────────┐
                    │   ImageNet        │
                    │   "Это собака"    │
                    └────────┬─────────┘
                             │
        ┌────────────────────┼────────────────────┐
        ▼                    ▼                    ▼
┌───────────────┐  ┌──────────────────┐  ┌──────────────────┐
│ Classification │  │  Detection       │  │   Segmentation   │
│ "Что? (один)" │  │ "Что? + Где?"    │  │ "Какой пиксель?" │
└───────┬───────┘  └────────┬─────────┘  └────────┬─────────┘
        │                   │                      │
    "собака"         "собака [120,50,300,400]"    маска
```

### Сравнительная таблица

| Аспект | Classification | Detection | Semantic Seg |
|--------|---------------|-----------|--------------|
| **Выход** | Вектор K | Boxes × K | H×W×K |
| **Количество объектов** | Один (обычно) | Переменное | Попиксельно |
| **Позиция объектов** | ❌ Не важна | ✅ Bbox | ✅ Маска |
| **Форма объектов** | ❌ | ❌ (прямоугольник) | ✅ Точная |
| **Инстансы** | ❌ | ✅ | ❌ |
| **Сложность** | Низкая | Высокая | Средняя |
| **Потеря** | CE | CE + box regression | CE + Dice |

### Детекция vs Классификация

```
Classification:
  "Изображение содержит собаку" (один ответ)

Detection:
  "Изображение содержит:
   - собаку 1 (x1,y1,x2,y2) с уверенностью 0.95
   - кошку   (x3,y3,x4,y4) с уверенностью 0.87"
```

**Ключевые отличия:**

1. **Переменный выход**: классификация — фиксированный K, детекция — произвольное N
2. **Пространственная локализация**: в классификации не нужна, в детекции — основная задача
3. **Множественные объекты**: классификация — один класс (top-1/top-5), детекция — все
4. **Фон vs объект**: классификация различает классы, детекция ещё и «фон/объект»
5. **Пост-обработка**: в детекции — NMS (non-maximum suppression), в классификации — нет

### Детекция vs Сегментация

```
Detection:
  Прямоугольник вокруг собаки: (120,50)-(300,400)

Semantic Segmentation:
  Каждый пиксель внутри собаки: class=dog

Instance Segmentation:
  Каждый пиксель собаки 1: class=dog, id=1
  Каждый пиксель собаки 2: class=dog, id=2
```

## 6. Подходы к детекции: краткий обзор

Детали двух- и одностадийных подходов — в [[DL 22 - Two-stage detection]] и [[DL 23 - One-stage detection]].
Метрики оценки детекции — в [[DL 21 - Метрики и NMS в детекции]].

### Two-stage (области → классификация)

1. **R-CNN** (2014): Selective Search → warp → classify
2. **Fast R-CNN** (2015): SS → RoIPool → joint training
3. **Faster R-CNN** (2015): RPN → end-to-end
4. **Cascade R-CNN** (2018): Multiple stages of refinement

### One-stage (прямая регрессия)

1. **YOLO** (2016): Grid → bbox + class
2. **SSD** (2016): Multiscale feature maps
3. **RetinaNet** (2017): Focal Loss + FPN
4. **YOLOv3/4/5/8**: Continuous improvements

### Transformer-based

1. **DETR** (2020): End-to-end, no anchors/NMS
2. **Deformable DETR** (2021): Deformable attention
3. **DINO** (2022): SOTA detection with transformers

## 7. Структура современного детектора

### Компоненты

```
┌────────────────┐     ┌────────────────┐     ┌────────────────┐
│   Backbone     │────▶│      Neck      │────▶│      Head      │
│  (ResNet,      │     │  (FPN, PAN,     │     │  (classification│
│   ConvNeXt,    │     │   BiFPN)        │     │   + regression) │
│   Swin)        │     │  multiscale     │     │                 │
└────────────────┘     └────────────────┘     └────────────────┘
```

| Компонент | Функция |
|-----------|---------|
| **Backbone** | Извлечение признаков (feature maps) |
| **Neck** | Мультимасштабная агрегация признаков |
| **Head** | Классификация + регрессия bbox для каждого anchor/query |

---

## Ключевые выводы к экзамену

1. **Object Detection** — локализация (bbox) + классификация всех объектов
2. **Bounding box** — $(x_1,y_1,x_2,y_2)$ или $(c_x,c_y,w,h)$
3. **Confidence** — уверенность модели в предсказании (0-1)
4. **IoU** — $\frac{|A \cap B|}{|A \cup B|}$, основа для метрики, матчинга и NMS
5. **Отличие от classification**: детекция — выходы переменной длины, пространственная локализация
6. **Отличие от segmentation**: детекция — bbox (нет точной формы), меньше деталей
7. **Современный детектор**: backbone → neck (multiscale) → head (cls + reg)

Детекция также используется как первый этап в instance-сегментации (Mask R-CNN) — [[DL 18 - Instance, Panoptic, Pose Estimation]].
