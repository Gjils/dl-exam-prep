# 32. Механизм внимания

## 1. Концепция Attention

**Определение:** внимание — механизм, позволяющий модели динамически выбирать, на какие части входных данных "смотреть" при генерации каждого выходного элемента.

**Аналогия:** человек переводит предложение, смотря на слово, которое переводит сейчас, но также "краем глаза" видя остальные.

---

## 2. Query, Key, Value (QKV)

### 2.1 Основная идея

Три роли для каждого элемента последовательности:

- **Query (Q):** "что я ищу?" — текущий элемент задаёт вопрос.
- **Key (K):** "насколько я релевантен?" — каждый элемент отвечает, насколько он важен для Query.
- **Value (V):** "какую информацию я несу?" — содержимое элемента.

**Аналогия (поиск в библиотеке):**
- Query = тема книги, которую вы ищете.
- Key = аннотация каждой книги на полке.
- Value = сама книга.

Впервые внимание было применено в [[DL 30 - Seq2seq и attention|seq2seq с RNN]] (Bahdanau, 2015), а затем стало центральным механизмом [[DL 33 - Архитектура Transformer|Transformer]]. Детальная математика — в вопросе 30.

### 2.2 Формальное определение

Пусть есть $T$ элементов. Для каждого $i$:
- $q_i$ — query для элемента $i$ (размерность $d_k$).
- $k_i$ — key для элемента $i$ (размерность $d_k$).
- $v_i$ — value для элемента $i$ (размерность $d_v$).

**Выход внимания для query $q_i$:**
$$
\text{Attention}(q_i, K, V) = \sum_{j=1}^{T} \alpha_{ij} v_j
$$

где $\alpha_{ij}$ — вес внимания (насколько $i$ смотрит на $j$).

---

## 3. Scaled Dot-Product Attention

### 3.1 Определение (Vaswani et al., 2017)

Основной тип внимания в Transformer.

**Формула:**
$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V
$$

где:
- $Q \in \mathbb{R}^{T \times d_k}$, $K \in \mathbb{R}^{T \times d_k}$, $V \in \mathbb{R}^{T \times d_v}$.
- $d_k$ — размерность keys/queries.

### 3.2 Пошагово

1. **Score matrix:** $S = QK^T$, размер $T \times T$.
   - $S_{ij} = q_i \cdot k_j$ — скалярное произведение.

2. **Scaling:** $S / \sqrt{d_k}$.
   - Зачем: для больших $d_k$ дисперсия скалярного произведения растёт ($\sim d_k$), что отправляет значения softmax в регионы с очень маленькими градиентами.
   - $\sqrt{d_k}$ нормализует дисперсию к 1.

3. **Softmax (row-wise):** $\alpha_{ij} = \frac{\exp(S_{ij} / \sqrt{d_k})}{\sum_{j'} \exp(S_{ij'} / \sqrt{d_k})}$.

4. **Weighted sum:** $\text{output}_i = \sum_{j} \alpha_{ij} v_j$.

### 3.3 Масштабирование (Scaling) — почему $\sqrt{d_k}$?

Пусть $q_i$ и $k_j$ — независимые случайные векторы с элементами $\sim \mathcal{N}(0, 1)$. Тогда:
$$
q_i \cdot k_j = \sum_{m=1}^{d_k} q_{i,m} k_{j,m}
$$

Дисперсия суммы:
$$
\text{Var}(q_i \cdot k_j) = d_k \cdot \text{Var}(q_{i,m})\text{Var}(k_{j,m}) = d_k
$$

Делим на $\sqrt{d_k}$ → дисперсия = 1.

**Без масштабирования:** softmax становится почти one-hot (attention на одном элементе), градиенты → 0.

### 3.4 Вычислительная сложность

$$
\text{Complexity} = O(T^2 \cdot d_k)
$$

- $T$ — длина последовательности.
- Квадратичная сложность — главный недостаток Transformer для длинных последовательностей.

## 4. Multi-Head Attention

### 4.1 Мотивация

Одно внимание — один тип отношений между элементами. Разные "головы" могут учить разные аспекты:
- Голова 1: синтаксические зависимости (субъект-глагол).
- Голова 2: семантические (синонимы).
- Голова 3: позиционные (слова рядом).

### 4.2 Определение

У нас $H$ голов внимания. Для каждой головы $h$:

$$
\text{head}_h = \text{Attention}(QW_h^Q, KW_h^K, VW_h^V)
$$

где $W_h^Q \in \mathbb{R}^{d_{\text{model}} \times d_k}$, $W_h^K \in \mathbb{R}^{d_{\text{model}} \times d_k}$, $W_h^V \in \mathbb{R}^{d_{\text{model}} \times d_v}$ — проекции.

**Конкатенация и выходная проекция:**
$$
\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_H) W^O
$$

где $W^O \in \mathbb{R}^{H d_v \times d_{\text{model}}}$.

### 4.3 Параметры в оригинальном Transformer

- $d_{\text{model}} = 512$.
- $H = 8$ голов.
- $d_k = d_v = d_{\text{model}} / H = 64$.

**Следствие:** сложность Multi-Head $O(T^2 \cdot d_{\text{model}})$ — та же, что одного head, т.к. $H \cdot d_k = d_{\text{model}}$.

### 4.4 Типы Multi-Head Attention в Transformer

**(a) Self-attention (самовнимание):** $Q = K = V$ = один и тот же слой.

**(b) Cross-attention (перекрёстное внимание):** $Q$ от декодера, $K, V$ от энкодера.

**(c) Masked attention:** $Q, K, V$ от декодера, но маскируем будущие позиции.

## 5. Типы Attention

### 5.1 По источникам Q, K, V

| Тип | Q | K, V | Применение |
|---|---|---|---|
| **Self-attention** | Из слоя X | Из того же слоя X | Encoder, Decoder (внутренние слои) |
| **Cross-attention** | Из декодера | Из энкодера | Encoder-Decoder (seq2seq) |
| **Encoder-decoder attention** | Из декодера | Из энкодера | То же, что cross-attention |
| **Source-target attention** | Целевая последовательность | Исходная | То же |

### 5.2 По геометрии (hard vs soft)

| Тип | Описание |
|---|---|
| **Soft attention** | Взвешенная сумма всех элементов (дифференцируемо) |
| **Hard attention** | Выбор одного элемента (argmax, недифференцируемо, Reinforcement Learning) |
| **Sparse attention** | Attention только на subset элементов (по маске, по окну) |
| **Global-Local attention** | Комбинация глобального и оконного внимания |

### 5.3 По методу вычисления alignment

| Тип | Формула | Параметры |
|---|---|---|
| **Dot-product** | $q \cdot k$ | 0 (нет) |
| **Scaled dot-product** | $(q \cdot k) / \sqrt{d_k}$ | 0 |
| **Additive (Bahdanau)** | $v_a^T \tanh(W_a q + U_a k)$ | MLP (веса) |
| **General (Luong)** | $q^T W_a k$ | Матрица $W_a$ |
| **Bilinear** | $q^T W_a k$ | То же, что General |

### 5.4 По маскированию

| Тип | Описание |
|---|---|
| **Full/Unmasked** | Все позиции видят все (encoder self-attention) |
| **Causal/Masked** | Позиция $t$ видит только $1..t$ (decoder self-attention) |
| **Padding mask** | Игнорировать padding-токены |
| **Sliding window attention** | Видеть только соседние $w$ позиций |
| **Dilated attention** | Разреженное внимание с шагом |

### 5.5 Эффективные варианты (для длинных последовательностей)

| Метод | Сложность | Идея |
|---|---|---|
| **Sparse Attention (Reformer)** | $O(T \log T)$ | LSH (locality-sensitive hashing) |
| **Linformer** | $O(T)$ | Low-rank проекция K/V |
| **Longformer** | $O(Tw)$ | Sliding window + глобальный attention |
| **BigBird** | $O(T)$ | Sliding + random + global attention |
| **FlashAttention** | $O(T^2)$ (оптимизация) | Tiling на GPU, без материала $T \times T$ матрицы |

## 6. Математическая сводка

**Attention = взвешенная сумма по Value, где веса зависят от совместимости Query и Key.**

$$
\text{Attention}(Q, K, V) = \underbrace{\text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)}_{\text{веса } \alpha_{ij}} \cdot V
$$

**Multi-Head Attention:** $H$ параллельных attention + конкатенация.

**Self-attention:** $Q$ = $K$ = $V$ = вход.

**Визуализация:** attention weights $\alpha_{ij}$ можно визуализировать как heatmap — строки = queries, столбцы = keys.

---

## 7. Итог

- **Q, K, V:** query (что ищу), key (насколько релевантен), value (что несу).
- **Scaled dot-product attention:** $\text{softmax}(QK^T / \sqrt{d_k}) V$ — основа Transformer.
- **Multi-Head:** $H$ разных attention heads для разных отношений.
- **Типы attention:** self, cross, masked; soft/hard; dot-product/additive.
- **Ключевая проблема:** $O(T^2)$ — квадратичная сложность.
