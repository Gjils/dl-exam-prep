# 62. Оценка и ограничения мультимодальных моделей

## 1. Бенчмарки для VLM

### VQAv2 (Visual Question Answering v2)

**Формат:** изображение + вопрос → ответ.

- **Размер:** ~265K изображений, ~1.1M вопросов
- **Типы вопросов:** object counting, color, location, relationships, yes/no
- **Метрика:** accuracy (точность ответа)
- **Проблема:** strong language priors — можно угадать без изображения

**Пример:**
```
Изображение: теннисный корт
Вопрос: "Какого цвета мяч?"
Ответ: "Желтый"
```

**Баллансировка:** каждой паре (image, question) соответствует 2 разных изображения с разными ответами → модель не может полагаться на текст.

### GQA (Graph Question Answering)

**Формат:** структурированные вопросы на основе Scene Graph.

- **Scene Graph:** формальное представление объектов, атрибутов и отношений
- **Вопросы:** сгенерированы из scene graph (логические цепочки)
- **Метрика:** accuracy + consistency (логическая согласованность)
- **Особенность:** проверка способности к композиционным рассуждениям

**Пример:**
```
Scene Graph: cat(on sofa), sofa(near table)
Вопрос: "Is the cat sitting on the sofa next to the table?"
Ответ: "Yes"
```

### MMBench

**MMBench** (Liu et al., 2023) — бенчмарк для оценки VLM по 20 категориям.

| Категория | Описание | Пример |
|---|---|---|
| **Perception** | Восприятие | Цвет, форма, размер |
| **Recognition** | Распознавание | Объекты, лица, OCR |
| **Knowledge** | Знания | Что на картинке, исторический контекст |
| **Reasoning** | Рассуждение | Почему, как, причинно-следственные связи |
| **Cognition** | Когнитивные | Творчество, юмор, абстракции |

**Формат:** multiple-choice (A/B/C/D) — 2974 вопроса.

**Поддержка:** multi-choice с изображениями, текстом, диаграммами.

**Проблема:** может быть решён через сильные языковые priors.

### MMMU (Massive Multi-discipline Multimodal Understanding)

**MMMU** (Yue et al., 2023) — самый сложный бенчмарк для мультимодальных моделей.

- **6 дисциплин:** Arts & Design, Business, Science, Health & Medicine, Humanities & Social Science, Engineering & Technology
- **30 предметов** (College-level)
- **11.5K вопросов** (multiple-choice + open-ended)
- **Форматы:** изображения, диаграммы, графики, таблицы, формулы
- **Сложность:** требует экспертных знаний

**Пример задач:**
```
Дисциплина: Physics
Вопрос: "На основе диаграммы Feynman, какая частица обменивается?"
Изображение: диаграмма Feynman
```

**Результаты MMMU (2024):**

| Модель | Accuracy |
|---|---|
| GPT-4o | ~78% |
| Gemini 1.5 Pro | ~70% |
| LLaVA-NeXT-34B | ~55% |
| BLIP-2 | ~42% |
| Random chance | 25% |

## 3. Метрики оценки

### Accuracy (для VQA, multi-choice)

$$Acc = \frac{1}{N} \sum_{i=1}^N \mathbb{1}[pred_i = gt_i]$$

Для VQAv2: open-ended accuracy — ответ считается правильным, если совпадает с любым из 10 ответов от людей.

### BLEU / ROUGE / CIDEr (для captioning)

| Метрика | Идея |
|---|---|
| **BLEU** | n-gram precision (сколько n-gram совпало с эталоном) |
| **ROUGE-L** | Длина наибольшей общей подпоследовательности (LCS) |
| **CIDEr** | TF-IDF взвешенные n-gram (отдаёт приоритет редким словам) |
| **SPICE** | Scene Graph совпадение (лучше для семантики) |

### FID / CLIP Score / Image Reward (для text-to-image)

| Метрика | Описание |
|---|---|
| **FID** | Расстояние между распределениями реальных и сгенерированных признаков |
| **CLIP Score** | Среднее косинусное сходство (image, text) через [[DL 60 - CLIP|CLIP]] |
| **ImageReward** | Human preference predictor |
| **PickScore** | Pick-a-pic based score |

### Human Evaluation

- **Preference rate:** % случаев, когда люди предпочли модель
- **A/B testing**
- **Likert scale:** 1-5 оценка

## 4. Multi-image режим

### Задачи:

| Задача | Описание | Пример |
|---|---|---|
| **Image comparison** | Сравнение двух изображений | "Какое крупнее?" |
| **Multi-view reasoning** | Несколько ракурсов | "Что на 3-м слайде?" |
| **Temporal reasoning** | Последовательность кадров | "Собака бежала?" |
| **Image set analysis** | Поиск общего | "Что общего?" |

### Проблемы multi-image:

1. **Position bias:** модель помнит порядок изображений, а не содержание
2. **Context length:** много визуальных токенов → long context
3. **Inter-image attention:** модель не видит cross-image отношения (только конкатенацию)
4. **Resolution:** каждое изображение сжимается

### Решения:
- **RoPE expansion** (для длинного контекста)
- **Interleaved encoding** (Flamingo: visual tokens + separator tokens)
- **Cross-attention** (Qwen-VL: resampler с attention на множественные изображения)

### MMMU Multi-Image:

MMMU включает подраздел multi-image, где несколько изображений составляют один вопрос. Это сильно сложнее, чем single-image.

## 5. Типичные ошибки VLM

### Hallucination (Галлюцинации)

**Несуществующие объекты:** модель утверждает, что видит объект, которого нет.

**Пример:**
```
Изображение: пустое офисное кресло
Модель: "Человек сидит в офисном кресле"
```

**POPE (Polling-based Object Probabilistic Evaluation):** бенчмарк для галлюцинаций — спрашивает о наличии/отсутствии объекта.

| Тип галлюцинации | Пример |
|---|---|
| **Object hallucination** | "Кошка на диване" (кошки нет) |
| **Attribute hallucination** | "Машина красная" (на самом деле синяя) |
| **Relation hallucination** | "Кошка на стуле" (рядом, но не на стуле) |
| **Position hallucination** | "Слева" (на самом деле справа) |

### Counting errors

**Проблема:** VLM плохо считают объекты (особенно >5)

**Пример:**
```
Изображение: 7 яблок
Модель: "Пять яблок"
```

### Spatial reasoning errors

**Проблема:** путает left/right, above/below, in front/behind

### Text rendering errors (OCR)

- Неправильно читает текст в изображении
- Особенно сложно: рукописный текст, мелкий шрифт, искривлённый текст

### Compositional reasoning

**Пример:**
```
Изображение: мальчик держит красный шар, рядом девочка с синим
Вопрос: "У кого синий шар?"
Ошибка: "У мальчика" (путает атрибуты)
```

### Failure modes summary:

| Тип ошибки | Причина | Частота |
|---|---|---|
| **Hallucination** | Модель "додумывает" | Высокая |
| **Object counting** | Нет счётного механизма | Высокая (>5 объектов) |
| **Spatial reasoning** | Позиционное кодирование не идеально | Средняя |
| **OCR blur** | Разрешение визуальных токенов | Средняя |
| **Compositional** | Композиционное понимание слабое | Средняя |
| **Temporal (video)** | Потеря информации между кадрами | Высокая |
| **Multi-image** | Сложность cross-image внимания | Высокая |

### Топ модели:

| Модель | Компания | Архитектура | Параметры | MMMU |
|---|---|---|---|---|

| **Llama 3.2 90B Vision** | Meta | ViT + LLaMA-3 | 90B | ~65% |

### Тренды:

1. **Multimodal native:** GPT-4o, Gemini обучаются на всех модальностях сразу
2. **Long context:** Gemini 1.5 Pro до 10M токенов (видео + аудио)
3. **Native video/audio:** прямое понимание аудио и видео
4. **Native multi-image:** улучшенная работа с несколькими изображениями
5. **Agentic VLM:** модели, которые могут действовать (браузер, инструменты)
6. **Resolution scaling:** динамическое разрешение для деталей
7. **Safety & alignment:** контент-фильтрация

### Современные вызовы:

| Вызов | Статус |
|---|---|
| **MMMU above 80%** | Не достигнут (кроме GPT-4o, близко) |
| **Zero generalization** | Не работает на новых концептах |
| **Video understanding** | Далеко от человеческого |
| **3D understanding** | Слабое |
| **Trustworthy VLM** | Галлюцинации не решены |
| **Efficiency** | Гигантские модели требуют суперкомпьютеров |
| **Multilingual** | Английский доминирует |
