# DL 01 — Введение в Deep Learning

## 1. Что такое Deep Learning?

**Deep Learning (DL)** — подраздел машинного обучения, использующий многослойные [[DL 02 - Нейронная сеть как композиция функций|нейронные сети (глубокие архитектуры)]] для извлечения иерархических представлений из данных.

Ключевое отличие: [[DL 02 - Нейронная сеть как композиция функций|**глубина** — цепочка из множества нелинейных преобразований]], каждое из которых учится представлять данные на всё более абстрактном уровне.

---

## 2. Отличия Deep Learning от классического ML

| Характеристика | Классическое ML | Deep Learning |
|---|---|---|
| **Признаки (features)** | Ручное проектирование (feature engineering) | Автоматическое извлечение из сырых данных |
| **Масштаб данных** | Работает на тысячах примеров | Требует десятки/сотни тысяч примеров |
| **Вычислительные ресурсы** | CPU достаточно | GPU/TPU обязательны для больших моделей |
| **Интерпретируемость** | Высокая (деревья, линейные модели) | Низкая («чёрный ящик») |
| **Сложность модели** | Ограниченная (глубина 1–2 уровня) | Огромная (сотни слоёв, миллионы параметров) |
| **Работа с неструкт. данными** | Слабая (требует агрессивной предобработки) | Естественная (текст, звук, изображения) |
| **Трансферное обучение** | Ограниченное | Мощное (предобученные модели) |

### Что DL делает лучше всех:
- **Иерархическое представление**: первый слой — простые паттерны (рёбра, углы), последующие — сложные концепции (лица, объекты).
- **End-to-end обучение**: от сырых данных к ответу без ручного выделения признаков.
- **Масштабирование**: with more data and compute, performance continues to improve (в отличие от классических методов, которые выходят на плато).

## 3. Типы данных в DL

| Тип данных | Примеры | Представление | Архитектура |
|---|---|---|---|
| **Табличные** | CSV, SQL, логи | Числовые/категориальные векторы | MLP (многослойный персептрон) |
| **Изображения** | Фото, рентген, спутник | Тензор $H \times W \times C$ | CNN |
| **Текст / последовательности** | Предложения, документы | Последовательность токенов / эмбеддингов | RNN, Transformer |
| **Временные ряды** | Цены акций, ECG | Последовательность скаляров/векторов | RNN, TCN, Transformer |
| **Аудио / Речь** | Запись разговора | Спектрограмма $T \times F$ / 1D сигнал | CNN, RNN, Transformer |
| **Графы** | Соцсети, молекулы | Матрица смежности + признаки узлов | GNN |
| **3D / Воксели** | LiDAR, CT | 3D тензор / Point cloud | 3D CNN, PointNet |
| **Мультимодальные** | Текст + изображение | Несколько тензоров разных типов | CLIP, LLaVA, GPT-4V |

## 4. Типы задач в DL

### 4.1. Контролируемое обучение (Supervised)
- **Классификация**: назначить метку классу (кошка vs собака)
- **Регрессия**: предсказать непрерывное значение (цена дома)
- **Обнаружение объектов (Object Detection)**: bounding boxes + класс каждого объекта
- **Сегментация**: попиксельная классификация (медицинские изображения)
- **Seq2Seq**: перевод, суммаризация текста

### 4.2. Неконтролируемое (Unsupervised)
- **Кластеризация**: группировка похожих объектов
- **Понижение размерности**: autoencoders, UMAP
- **Генерация**: GAN, VAE, Diffusion

### 4.3. Обучение с подкреплением (Reinforcement Learning)
- Агент учится через взаимодействие со средой (Games, Robotics, LLM fine-tuning через RLHF)

### 4.4. Самообучение (Self-supervised)
- Модель учится на немаркированных данных через вспомогательные задачи:
  - **BERT**: маскирование слов → предсказание
  - **SimCLR**: contrastive learning для изображений
  - **MAE (Masked Autoencoder)**: восстановление замаскированных патчей

## 5. Ключевые идеи Deep Learning

### 5.1. Gradient-Based Optimization
Вся DL построена на [[DL 05 - Оптимизация|градиентном спуске]]. Модель — дифференцируемая функция $f(x; \theta)$, оптимизация через [[DL 04 - Backpropagation и autodiff|backpropagation]] + [[DL 05 - Оптимизация|SGD/Adam]].

### 5.2. Сквозное обучение (End-to-End)
$$y = f_{\theta}(x) \quad \text{— одна дифференцируемая цепочка от входа до потерь}$$

Вся модель обучается одновременно, а не поэтапно.

### 5.3. Иерархия представлений
Каждый слой учит всё более абстрактные признаки:

```
Пиксели → Рёбра → Углы → Части объекта → Объект
```

### 5.4. Вычислительные возможности (GPU)
Матричные операции линейных слоёв и свёрток идеально параллелятся на GPU благодаря CUDA.

### 5.5. Эффект масштаба (Scaling Laws)
С увеличением размера модели, данных и compute performance растёт предсказуемо (Kaplan et al., Hoffmann et al.).

### 5.6. [[DL 15 - Transfer Learning|Трансферное обучение]]
Предобученная модель на огромном датасете (ImageNet, Wikipedia) дообучается (fine-tune) на целевой задаче с малым количеством данных.

### 5.7. [[DL 06 - Стабилизация и регуляризация|Регуляризация через глубину]]
Глубокие сети требуют специальных техник ([[DL 06 - Стабилизация и регуляризация|BatchNorm, Dropout, Residual connections, AdamW]]), без которых обучение нестабильно.

## 6. Краткая история (важные вехи)

| Год | Событие |
|---|---|
| 1958 | Персептрон Розенблатта |
| 1986 | Backpropagation (Rumelhart, Hinton, Williams) |
| 1998 | LeNet-5 (Yann LeCun) — первая CNN |
| 2006 | Deep Belief Networks (Hinton) — начало современного DL |
| 2012 | AlexNet побеждает ImageNet с отрывом → эра DL |
| 2014 | GANs (Goodfellow) |
| 2017 | Transformer (Vaswani et al.) |
| 2020 | GPT-3 → эра Foundation Models |
| 2022 | Stable Diffusion, ChatGPT |
| 2023–2025 | LLM, Multimodal AI, Agentic AI |

---

## 7. Резюме

- **Deep Learning** = многослойные нейросети, обучаемые сквозным градиентным спуском.
- Главное отличие от ML: **автоматическое извлечение признаков + масштабирование с данными**.
- Работает с любыми типами данных: изображения, текст, звук, графы, 3D.
- Ключевые идеи: [[DL 04 - Backpropagation и autodiff|backpropagation]], GPU, иерархия представлений, [[DL 15 - Transfer Learning|трансферное обучение]], scaling laws.
