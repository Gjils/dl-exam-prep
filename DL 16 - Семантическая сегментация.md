# 16. Семантическая сегментация

## Постановка, отличия от классификации, FCN, encoder-decoder, superpixels

---

## 1. Постановка задачи

### Определение
**Семантическая сегментация** — задача попиксельной классификации: каждому пикселю изображения присваивается метка класса.

$$ \mathcal{I}: \Omega \to \mathbb{R}^{H \times W \times C} \quad \rightarrow \quad \mathcal{S}: \Omega \to \{1, \ldots, K\}^{H \times W} $$

Где:
- $\Omega = \{1,\ldots,H\} \times \{1,\ldots,W\}$ — пространство пикселей
- $K$ — количество классов
- $C$ — количество каналов (3 для RGB)

### Формально
Найти $f_\theta: \mathbb{R}^{H \times W \times C} \to \{1,\ldots,K\}^{H \times W}$ такую, что маска сегментации совпадает с ground truth.

**Выход**: тензор $H \times W \times K$ (logits для каждого класса в каждом пикселе), затем argmax по K.

---

## 2. Отличия от классификации

| Характеристика | Классификация | Семантическая сегментация |
|----------------|---------------|--------------------------|
| **Вход** | Изображение $H \times W \times C$ | Изображение $H \times W \times C$ |
| **Выход** | Вектор $K$ (один класс на всё изображение) | Тензор $H \times W \times K$ (класс на пиксель) |
| **Потеря** | Cross-entropy по классам | Cross-entropy по пикселям |
| **Пространственная структура** | Не важна (усреднение) | Критически важна |
| **Рецептивное поле** | Должно охватить всё изображение | Должно быть достаточно для контекста |
| **Размер выхода** | $K$ (небольшой) | $H \times W$ (огромный) |

### Почему классификацию нельзя использовать для сегментации
- Полносвязные слои теряют пространственную информацию
- Max/Avg Pooling уничтожает точные позиции объектов
- Выход — вектор, а не карта

### Связь с detection
| Задача | Выход |
|--------|-------|
| Classification | Один label на изображение |
| Object Detection | Bounding boxes + labels |
| Semantic Segmentation | Попиксельные метки (без разделения инстансов) |
| Instance Segmentation | Попиксельные метки **с разделением инстансов одного класса** |
| Panoptic Segmentation | Semantic + Instance вместе |

## 3. FCN (Fully Convolutional Network)

### Ключевая идея (Long et al., 2015)
Заменить все FC-слои на **1×1 свёртки**. Это позволяет:
- Обрабатывать изображения **любого размера**
- Сохранять пространственную карту признаков
- Выходить с картой, а не вектором

### От классификации к FCN

```
[Conv] [Conv] ... [Conv] [FC] [FC] → [FC 1000]
         ↓
[Conv] [Conv] ... [Conv] [1×1 Conv] [1×1 Conv] → [1×1 Conv K] → Upsample
```

**Преобразование FC в Conv**:
- FC с 4096 нейронами → 1×1 Conv с 4096 фильтрами
- Последний FC → 1×1 Conv с K фильтрами

### Up-sampling в FCN

**Проблема**: после серии свёрток и pooling размер карты признаков уменьшен в 32 раза (stride 32).

**Решение**: Транспонированная свёртка (transposed convolution / deconvolution).

#### Transposed Convolution
- "Развёртка": каждый входной пиксель умножается на kernel и заполняет выход
- Обучаемый upsampling

$$ \text{Output size} = (Input - 1) \times stride + kernel - 2 \times padding $$

### FCN-32s, FCN-16s, FCN-8s

Архитектура с **skip connections** для улучшения детализации:

| Версия | Upsample путь | Детализация |
|--------|--------------|-------------|
| **FCN-32s** | pool5 → 32× up → prediction | Грубая |
| **FCN-16s** | pool5 → 2× up + pool4 → 16× up | Средняя |
| **FCN-8s** | pool5 → 2× up + pool4 → 2× up + pool3 → 8× up | Лучшая |

**Skip connection**: конкатенация/суммирование карт признаков с разных уровней:
- Pool4 (stride 16) — средний уровень (контуры)
- Pool3 (stride 8) — мелкий уровень (детали)

## 4. Encoder-Decoder архитектура

### Общая схема

```
Input Image
    │
    ▼
┌────────────────┐
│   ENCODER      │  ↓ downsampling (stride 32 или меньше)
│  (backbone)    │
│  Conv → BN →   │
│  ReLU → Pool   │  feature maps: H/32 × W/32 × C
└────────┬───────┘
         │
    Bottleneck / Bridge
         │
         ▼
┌────────────────┐
│   DECODER      │  ↑ upsampling к H × W
│  (upsample)    │
│  UpConv → BN → │
│  ReLU          │  feature maps: H × W × K
└────────────────┘
    │
    ▼
Segmentation Map (H × W)
```

### Encoder (backbone)
- Предобученная CNN (VGG, ResNet, EfficientNet)
- Уменьшает пространственное разрешение
- Увеличивает число каналов
- **Извлекает семантические признаки**

### Decoder
- Восстанавливает пространственное разрешение
- **Извлекает детали** из encoder через skip connections
- Обучаемый upsampling (transposed conv или interpolation + conv)

### Skip connections (мост между encoder и decoder)

```
Encoder: conv1 ── conv2 ── conv3 ── conv4 ── conv5 ── bottleneck
            │        │        │        │        │
            ▼        ▼        ▼        ▼        ▼
Decoder:   ─────────────────────────────────────── upsample ── out
```

Каждый skip connection передаёт feature map с соответствующего уровня encoder в decoder. Выравнивание каналов через 1×1 Conv.

### Почему encoder-decoder работает
- Encoder: **семантика** (что это за объект)
- Decoder: **позиция** (где этот объект)
- Skip connections: связывают семантику с позицией

## 5. Superpixels (суперпиксели)

### Определение
Группа соседних пикселей с похожими характеристиками (цвет, текстура). Переход от пикселей к группам.

### Алгоритмы

| Алгоритм | Идея | Сложность |
|----------|------|-----------|
| **SLIC** | K-means в 5D пространстве (Lab + xy) | $O(N)$ |
| **Felzenszwalb** | Графовая сегментация | $O(N \log N)$ |
| **SEEDS** | Градиентный спуск по энергии | $O(N)$ |
| **Quickshift** | Mode-seeking | $O(N^2)$ |

### SLIC (Simple Linear Iterative Clustering)

1. Дискретизация изображения на сетку шага $S$
2. K-means в пространстве $[L, a, b, x, y]$
3. Расстояние:
   $$ D = d_{lab} + \frac{m}{S} \cdot d_{xy} $$
   $$ d_{lab} = \sqrt{(l_i - l_j)^2 + (a_i - a_j)^2 + (b_i - b_j)^2} $$
   $$ d_{xy} = \sqrt{(x_i - x_j)^2 + (y_i - y_j)^2} $$
   - $m$ — компактность (больше → более регулярные формы)

### Применение superpixels в сегментации

1. **Pre-processing**: сгруппировать пиксели → superpixels → классифицировать superpixels
2. **Post-processing**: CRF (Conditional Random Fields) на superpixel-графе
3. **Efficiency**: обрабатывать меньше элементов ($\sim 10^3$ вместо $10^6$)

### Современное состояние
- С развитием deep learning superpixels **почти не используются** в энд-ту-энд моделях
- Иногда применяются для:
  - Edge detection (HED)
  - Визуализация attention
  - Speed-up при ограниченных ресурсах

## 6. Эволюция подходов (кратко)

| Год | Подход | Ключевая идея |
|-----|--------|--------------|
| До 2014 | Sliding window | Классификация патчей |
| 2014 | FCN | End-to-end, FC → Conv |
| 2015 | SegNet | Encoder-decoder без skip |
| 2015 | [[DL 17 - U-Net|U-Net]] | Encoder-decoder + skip (медицина) |
| 2016 | DeepLab v1 | Atrous conv, CRF post-processing |
| 2017 | DeepLab v2 | ASPP (Atrous Spatial Pyramid Pooling) |
| 2017 | PSPNet | Pyramid Pooling Module |
| 2018 | DeepLab v3 | Improved ASPP, encoder-only |
| 2019 | DeepLab v3+ | Encoder-decoder + ASPP |
| 2023 | SAM | Segment Anything — promptable |

## Ключевые выводы к экзамену

1. **Семантическая сегментация** — попиксельная классификация, выход $H \times W \times K$
2. **Отличие от классификации**: пространственная структура критична, выход — карта, не вектор
3. **FCN** — замена FC на 1×1 Conv + transposed conv upsampling
4. **Skip connections в FCN**: FCN-32s → FCN-16s → FCN-8s (улучшение детализации)
5. **Encoder-decoder**: encoder (семантика) + decoder (позиция) + skip connections
6. **Superpixels**: группировка пикселей, pre/post-processing, почти не используется в deep learning
