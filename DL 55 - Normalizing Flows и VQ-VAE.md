## Часть 1: Normalizing Flows

### 1. Основная идея

**Normalizing Flows** — класс генеративных моделей, которые строят сложное распределение $p_X(x)$ через последовательность обратимых (биективных) преобразований простого базового распределения $p_Z(z)$ (обычно $\mathcal{N}(0, I)$).

Идея:
$$z \sim p_Z(z) \quad \xrightarrow{f^{-1}} \quad x = f(z)$$
$$x \sim p_X(x) \quad \xrightarrow{f} \quad z = f^{-1}(x)$$

где $f$ — обратимое (invertible) и дифференцируемое преобразование.

### 2. Change of Variables Formula (Формула замены переменных)

Если $z = f^{-1}(x)$ и $f$ — биективное гладкое отображение, то:

$$p_X(x) = p_Z(f^{-1}(x)) \cdot \left|\det \frac{\partial f^{-1}(x)}{\partial x}\right|$$

Или эквивалентно, через прямое преобразование $x = f(z)$:

$$p_X(x) = p_Z(z) \cdot \left|\det \frac{\partial f(z)}{\partial z}\right|^{-1}$$

**Формула для логарифма:**

$$\log p_X(x) = \log p_Z(f^{-1}(x)) + \log \left|\det \frac{\partial f^{-1}(x)}{\partial x}\right|$$

**Ключевой момент:** определитель Якобиана должен быть легко вычислим. Поэтому в нормализующих потоках используют специальные архитектуры с **треугольным Якобианом**.

### 3. Normalizing Flow — композиция преобразований

Композиция обратимых функций — тоже обратимая функция:

$$f = f_K \circ f_{K-1} \circ \dots \circ f_1$$

Логарифм плотности:

$$\log p_X(x) = \log p_Z(z_K) + \sum_{k=1}^K \log \left|\det \frac{\partial f_k^{-1}(z_k)}{\partial z_k}\right|$$

где $z_0 = x$, $z_K = z$, $z_k = f_{k+1}^{-1}(z_{k+1})$.

### 4. Exact Likelihood (Точное правдоподобие)

Главное преимущество Normalizing Flows: они дают **точное** значение $\log p_X(x)$ (в отличие от VAE, который даёт нижнюю границу, и GAN, который вообще не даёт плотности).

$$\log p_\theta(x) = \log p_Z(f_\theta^{-1}(x)) + \log \left|\det J_{f_\theta^{-1}}(x)\right|$$

Это позволяет:
- Обучать модель максимизацией точного правдоподобия (MLE)
- Использовать модель для density estimation
- Сравнивать различные модели по likelihood

### 5. Архитектуры Normalizing Flows

#### Planar Flow (простейший)

$$f(z) = z + u \cdot h(w^\top z + b)$$

$h$ — нелинейность (например, tanh). Якобиан: $\det(I + u h'(w^\top z + b) w^\top)$.

Сложность: $O(D^3)$ для вычисления детерминанта.

#### Affine Coupling Layer (NICE, RealNVP)

Разбиваем $z$ на две части: $z_{1:d}$ и $z_{d+1:D}$.

$$y_{1:d} = z_{1:d}$$
$$y_{d+1:D} = z_{d+1:D} \odot \exp(s(z_{1:d})) + t(z_{1:d})$$

Якобиан — нижняя треугольная матрица:

$$\det J = \prod_{i=d+1}^D \exp(s_i(z_{1:d})) = \exp\left(\sum_i s_i(z_{1:d})\right)$$

Обратимо по построению:
$$z_{d+1:D} = (y_{d+1:D} - t(y_{1:d})) \odot \exp(-s(y_{1:d}))$$

#### Glow (Kingma & Dhariwal, 2018)

Добавляет:
- **Actnorm** — нормализация активаций (обучаемая сдвиг+масштаб)
- **1×1 invertible convolution** — перемешивание каналов (обучаемая матрица перестановки)
- **Affine coupling** — как в RealNVP

### 6. Достоинства Normalizing Flows

| Достоинство | Описание |
|---|---|
| **Exact likelihood** | Точное значение $\log p(x)$ — MLE обучение |
| **Inference и генерация** | Одно направление (быстрое) |
| **Нет адверсариального обучения** | Стабильное обучение (как автоencoder) |
| **Хорошая интерполяция** | Лакуны в латентном пространстве не возникают |
| **Density estimation** | Можно оценить плотность произвольной точки |

### 7. Недостатки Normalizing Flows

| Недостаток | Описание |
|---|---|
| **Обратимость** | Требует dim(z) = dim(x) — не сжимает |
| **Высокая вычислительная стоимость** | Каждый шаг потока требует расчёта Якобиана |
| **Ограниченная архитектура** | Сложно строить глубокие потоки |
| **Качество генерации** | Уступает GAN и диффузионным моделям |
| **Мало пропускной способности** | Требуется много слоёв для сложных распределений |
| **Сложность обучения** | Нестабильность при большом количестве слоёв |

### 8. Сравнение генеративных моделей

| Модель | Likelihood | Качество генерации | Инференс | Обучение |
|---|---|---|---|---|
| **VAE** | Нижняя граница (ELBO) | Среднее (размытое) | Быстрый | Стабильное |
| **GAN** | Нет | ✓ Отличное | Быстрый | ✗ Нестабильное |
| **Normalizing Flows** | Точное | Хорошее | Быстрый (оба напр.) | Стабильное |
| **Diffusion** | Вариационный нижний | Отличное | ✗ Медленный (итеративный) | Стабильное |

## Часть 2: VQ-VAE

### 1. Общая идея

**VQ-VAE** (Vector Quantized VAE, van den Oord et al., 2017) — вариант VAE с **дискретным латентным пространством**. Вместо непрерывного $z$, encoder выдаёт индексы из конечного набора (codebook).

### 2. Дискретное латентное пространство

Проблема: изображения, аудио, текст — по своей природе дискретны. Непрерывное латентное пространство может быть избыточным.

**Решение VQ-VAE:**
1. Encoder $E(x)$ выдаёт карту признаков $z_e(x) \in \mathbb{R}^{h \times w \times d}$
2. Каждый вектор $z_e^{(i,j)} \in \mathbb{R}^d$ заменяется на ближайший из codebook

### 3. Codebook

**Codebook** — обучаемый набор $K$ векторов-прототипов $\{e_1, e_2, \dots, e_K\}$, $e_k \in \mathbb{R}^d$.

**Процесс квантования:**

Для каждого позиционного вектора $z_e(x)_{ij}$ находим ближайший код:

$$z_q(x) = e_k, \quad \text{где } k = \arg\min_j \|z_e(x) - e_j\|_2$$

Квантованные векторы $z_q(x)$ подаются в Decoder $D(z_q)$.

**На выходе Decoder:** $\hat{x} = D(z_q(x))$

Схематично:
```
x → Encoder → ze(x) → [квантование по codebook] → zq(x) → Decoder → x̂
                                    ↑
                            обучаемый словарь K×d
```

### 4. Commitment Loss

Проблема: argmin не дифференцируем. Решение — straight-through estimator: градиент из decoder копируется через квантование к encoder (градиент от $z_q$ передаётся к $z_e$).

**Три члена loss:**

$$L = \underbrace{\log p(x|z_q(x))}_{\text{Reconstruction}} + \underbrace{\|sg[z_e(x)] - e\|_2^2}_{\text{Codebook loss}} + \underbrace{\beta \|z_e(x) - sg[e]\|_2^2}_{\text{Commitment loss}}$$

где $sg$ — stop-gradient (градиент не проходит).

Пояснение членов:

1. **Reconstruction**: стандартный loss VAE (через decoder)
2. **Codebook loss**: двигает коды $e$ к выходу encoder (только $e$ обучаются)
3. **Commitment loss**: двигает выход encoder к выбранному коду (только encoder обучается) c весом $\beta$ (обычно 0.25)

**Straight-through estimator:** градиент reconstruction loss проходит через квантование как identity:

$$\frac{\partial L}{\partial z_e(x)} \approx \frac{\partial L}{\partial z_q(x)}$$

### 5. Априорное распределение (Prior)

VQ-VAE не учит распределение над латентным пространством автоматически. После обучения VQ-VAE обучается **априорное распределение $p(z)$** — обычно авторегрессивная модель (PixelCNN над индексами codebook).

Для генерации:
1. Сэмплируем последовательность индексов из prior (PixelCNN)
2. Получаем $z_q$ из codebook по индексам
3. Декодируем в $\hat{x}$

### 6. VQ-VAE vs VAE — сравнение

| Характеристика | VAE | VQ-VAE |
|---|---|---|
| **Латентное пространство** | Непрерывное | Дискретное (codebook) |
| **Размерность латентного** | $\ll \dim(x)$ | $\sim \dim(x)$ (сжатие через codebook) |
| **Приор** | Фиксированный ($\mathcal{N}(0, I)$) | Обучаемый (PixelCNN/Transformer) |
| **Качество реконструкции** | Среднее (размытое) | ✓ Высокое |
| **Сложность обучения** | Средняя | Выше (codebook коллапс) |
| **Применение** | Генерация, anomaly detection | Сжатие, DALL-E, музык. генерация |

### 7. Codebook Collapse

**Проблема:** некоторые коды в codebook никогда не используются ("мёртвые коды").

**Решения:**
- **Exponential moving average (EMA) update**: обновление кодов как скользящее среднее
- **Restart**: замена мёртвых кодов на случайные $z_e$ из текущего батча
- **Снижение $\beta$**: уменьшение commitment loss

### 8. Применения VQ-VAE

| Модель | Описание |
|---|---|
| **DALL-E** | VQ-VAE для сжатия изображения + авторегрессивный Transformer |
| **VQ-GAN** | VQ-VAE с адверсариальным loss (GAN в decoder) |
| **Jukebox** | VQ-VAE для аудио |
| **Image GPT** | Дискретные пиксели (аналог VQ-VAE без codebook) |
| **Video generation** | VQ-VAE + временные трансформеры |
